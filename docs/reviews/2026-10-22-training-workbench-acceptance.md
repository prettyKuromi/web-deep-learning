## 历史 P1：回归 CSV 数值标签（已修复并复验）

**修复及复验结果**

a103166 后，本验收角色在独立 fresh Chrome 按“先导入 CSV，再选择回归”顺序复测成功：100 轮训练、启用 20% 验证集，训练/验证为 7/1；训练 MAE=0.2870、MSE=0.1010、R²=0.9935。刷新后历史详情保留指标和数据来源；分类/回归比较对不适用指标显示“不适用”；Markdown、HTML 报告依次导出且包含指标和 7/1 来源。最终 P1 计数为 0。开发侧另记录的 3 个 Chrome CSV 定向场景通过。

以下为修复前复现记录：

**复现步骤**

1. fresh Chrome 打开页面，点击任务 tab“回归”。
2. 上传 CSV：
   ```csv
   x1,x2,target
   0,0,1
   1,0,3
   0,1,4
   1,1,6
   2,1,8
   2,2,11
   3,1,10
   3,2,13
   ```
3. 点击“确认数据集并进入实验流程”，选择线性回归，迭代次数设为 30，启用验证集后点“开始训练”。
4. 页面显示“回归任务要求最后一列标签为有限数值，请更换数据集”；没有生成模型、指标或历史报告。

**源码证据**

- `src/features/datasets/dataset.ts` 的 `parseCsvDataset` 以 `Record<string, string>` 解析 CSV，`labels` 类型是 `string[]`，并将 `label` 原样加入数组。
- `src/App.tsx` 的训练前校验要求回归数据的每个 label 满足 `typeof label === 'number' && Number.isFinite(label)`。
- 两处数据契约不一致。该缺陷已在 a103166 修复；以上独立 Chrome 复测通过，故此历史 P1 已关闭。
