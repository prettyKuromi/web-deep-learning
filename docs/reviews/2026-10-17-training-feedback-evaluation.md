## 反馈真实性分类

- **已观察到的真实结果证据**：完成状态、第 200 步、最终损失、分类指标、混淆矩阵、逻辑回归权重及训练时间线均在完成后的页面呈现，并具有相互关联的训练结果形态。
- **无法确认的实时数据**：训练中进度、迭代与损失的刷新频率、估时、阶段事件及快照完整性。快速训练只观察到完成态，不能将静态完成结果视作实时反馈证据。
- **仅有 UI 控件但未确认行为**：暂停、单步、继续、停止。控件存在及其说明文案本身不证明 Worker 实际受控。

## 问题清单

### P1：训练中没有被验证到实时反馈，核心可信度缺少证据

- 复现：打开首页；确认“月牙形”并进入实验；选择逻辑回归；点击开始训练。本次下一份可观察快照已显示“训练完成”和第 200 步，未出现训练中的迭代/损失帧。
- 浏览器证据：完成态时间线仅能看见第 193–200 步，顶层状态是“训练完成”；按钮均不可用。页面在训练完成后显示结果，并不能说明训练阶段真实连续更新。
- 源码证据：受 shell/CET 错误限制，未能读取 Worker 和 UI 源码。
- 建议：以 Worker 发出的阶段/快照事件作为状态唯一来源；呈现当前步数/总步数、损失和适用的关键指标。对快照限频但设最大静默间隔；保留明确当前值和历史趋势。通过足够长的训练配置或测试夹具验证多个训练中采样点，而非仅验证最终页面。
- 验收标准：自动化实际运行时采集到至少三个训练中时点；步数单调递增且小于等于总步数，损失与快照事件一致；进度只由 Worker 步数计算；训练结束最终快照与最终指标对应。

### P1：控制按钮的 Worker 效果未经验证

- 复现：配置高迭代数训练，分别执行暂停、等待、单步、继续、停止并采集 Worker/UI 状态。本次 200 步训练在工具操作期间结束，无法执行可靠的中途控制序列。
- 浏览器证据：控件存在，完成后禁用；说明文字称单步为一个完整迭代、暂停等待本轮结束，但没有运行中观察证据。
- 源码证据：未能读取 Worker 消息协议或状态管理代码。
- 建议：按 Worker 接受的明确训练单位定义暂停/单步/恢复/取消，并用慢速或可控的长训练做端到端验证；训练中只允许适用的操作。
- 验收标准：暂停后等待一个可观测区间步数与指标不变；单步仅增加一个单位；继续从暂停步恢复；停止终止 Worker 且不产生后续快照，页面给出取消/停止状态。

### P2：图表语义及窄屏体验未得到验收

- 复现：在训练前、中、后分别检查曲线标题、轴、图例、当前值与历史趋势；再以 1024、768 和手机宽度调整视口检查布局与滚动。本次只在 1366×768 检查页面可访问性树和整体纵向尺寸。
- 浏览器证据：可访问性树对曲线仅提供名称“训练损失曲线”；页面显示训练时间线和最终指标；文档有纵向滚动。其余视口和图表细节未核实。
- 源码证据：未能读取图表组件或响应式样式。
- 建议：确保图表有可读标题、迭代/损失坐标语义、图例/当前值；各断点下状态、图表、操作控件不重叠且可滚动访问。
- 验收标准：1366、1024、768 和手机视口无横向溢出、按钮/数据不可达或遮挡；训练图和辅助文本都能说明数据、当前进度与趋势。

### P2：失败、取消、保存失败和旧结果失效尚未核实

- 复现：触发非法参数、Worker 异常、用户取消和存储失败；之后修改参数并观察结果区域与错误上下文。本次只跑了正常完成路径。
- 浏览器证据：页面具备独立“训练过程”及“当前结果”区域，正常完成显示指标；异常及参数变更行为未触发。
- 源码证据：无法检查错误处理、结果缓存失效及存储逻辑。
- 建议：验收时分别触发训练失败、取消、保存失败，确认状态不混淆；参数/数据变化后清除或标记陈旧结果，失败时保留上下文且不白屏。
- 验收标准：用户能分别识别失败、取消、完成、保存失败；参数或数据变更后旧结果不以当前结果呈现；错误提示中文且能指明下一步。
