# Web Deep Learning

面向机器学习初学者的浏览器端实验工作台。核心训练在本地 Worker 中运行，实验历史保存在本机浏览器，不依赖账号、后端或 GPU。

## 当前状态

项目已实现可运行的教学型实验闭环：选择任务、模型与数据，配置参数并训练，查看过程和结果，保存、比较与导出实验。当前实现不等同于生产级机器学习或深度学习平台。

## 已实现能力

- **分类：** KNN、逻辑回归、线性 SVM、感知机、决策树、随机森林、AdaBoost、朴素贝叶斯、MLP、可视化 CNN。
- **回归：** 线性回归、岭回归。
- **聚类：** K-Means、DBSCAN。
- **降维：** PCA。
- **数据：** 五种合成二维表格数据、两种本地生成的 8×8 灰度图像数据，以及简单 CSV 导入。
- **训练与分析：** Worker 训练、过程快照、支持模型的暂停/继续/单步、停止、可选验证集评估、模型说明、交互预测、数据剖析及任务结果可视化。
- **实验管理：** 浏览器 IndexedDB 保存最近 20 条实验，支持 JSON 导入/导出、历史比较及 Markdown/HTML 报告。

## 数据与评估限制

CSV 要求首行为表头，最后一列为目标，其余列必须是数值特征；缺失或非法特征行会跳过。当前没有面向用户的字段映射、类别特征编码、缺失值填补或通用自动标准化。部分模型对特征尺度敏感。

验证集划分为可选项，分类使用分层划分，回归使用随机划分。没有独立测试集、交叉验证或系统化参数搜索。分类和回归指标应结合评估口径理解。

图像任务只支持程序生成的教学样本，不能导入真实图片。CNN 是小型手写教学实现，不代表大型视觉任务的能力。算法和图表适用于小规模学习实验；项目没有大数据性能保证，实验历史最多保留 20 条。报告不记录代码版本和运行时版本。

## 本地开发

需要 Node.js 与 npm。

- 安装依赖：npm install
- 启动开发服务：npm run dev
- 运行单元测试：npm test -- --run
- 运行端到端测试：npm run e2e
- 静态检查：npm run lint
- 生产构建：npm run build
