# SDD-037：实验流程重入空态与主画布布局

- 状态：已确认，开发中
- 编号：037
- 创建日期：2026-10-23

## 1. 背景与目标

再次进入实验流程时，训练状态虽然会重置，但普通模型仍显示当前数据投影，CNN 仍显示网络编辑器，用户无法一眼分清这是新一轮实验的空白状态还是旧结果。桌面实验页采用配置、训练、解释结果三栏，核心训练画布只获得约一半横向空间。

本功能让每次进入实验流程都从明确的训练空态开始，并将桌面实验页调整为配置栏和主画布两栏，让训练过程成为主要内容。

本轮补充目标：桌面常见视口下，训练画布卡片应占满主画布剩余空间，训练图表、状态和控制项无需内部滚动即可完整展示。

## 2. 范围

### 包含

- 从准备页或其他顶层页面进入实验流程时，清空当前训练状态、进度、快照、错误、指标、当前实验引用、选中步骤及训练画布页签。
- 保留数据集、模型、模型参数、CNN 网络层配置、评估设置及历史实验。
- 未开始新训练时，训练过程画布展示空态，不展示上轮图表、数据投影或结果。
- 将 CNN 网络结构编辑入口放在画布内的独立页签；重进时默认选择训练过程页签。
- 桌面训练流程改为“配置栏 + 主画布”两栏；解释和结果整合到主画布的次级页签。
- 桌面常见视口下训练画布卡片扩展到可用高度，图表、状态和控制项完整可见，不出现卡片或画布内部滚动条。
- 在窄屏下配置区与主画布纵向排列，无横向溢出。

### 不包含

- 改变训练算法、训练状态机、数据集兼容规则和持久化格式。
- 清除或覆盖已保存的实验历史。
- 修改模型参数、数据集或 CNN 网络结构的保留策略。

## 3. 用户流程

1. 用户在准备页确认数据后进入实验流程，主画布显示“开始训练后，训练过程会显示在这里”的空态。
2. 用户在左侧选择算法、修改参数；若使用 CNN，可切到网络结构页编辑层配置。
3. 用户点击开始训练，主画布显示实时训练反馈和过程可视化。
4. 训练完成后，用户仍可在主画布查看训练过程，切换到结果页查看指标与解释。
5. 用户离开实验流程，再次进入时运行结果回到空态；当前配置和历史记录继续保留。

## 4. 技术方案

- 继续由 App 统一执行 enterWorkflow 与 resetTraining，避免各导航入口出现不同清理范围。
- SinglePageWorkbench 在无训练状态下不向 TrainingProgressChart 传入数据投影 fallback；训练结果只从当前训练状态和当前实验引用中读取。
- 主画布内部以页签组织训练过程、结果解释；CNN 另提供网络结构页签。进入工作流时页签默认为训练过程。
- 桌面布局使用固定宽度配置栏与弹性主画布，主画布至少占可用宽度的约三分之二。结果内容不再占独立右侧栏。
- 保持现有 CSS Grid 和响应式断点，不新增布局依赖。
- 工作流占用页面内容区的完整高度；训练卡片、图表和时间线按可用高度收缩/扩展，图表本身不启用滚动。

## 5. 数据结构/API

- 不新增持久化字段或 Worker 消息。
- SinglePageWorkbench 内部可增加画布页签状态；状态随页面离开后卸载，并在重新进入时初始化为训练过程。
- App 继续通过现有 resetTraining 清理训练运行状态、当前实验引用和选中训练步骤。

## 6. 错误处理

- 重入期间若存在未完成训练，仍通过 AbortController 中止旧任务，旧 Worker 不得覆盖新页面状态。
- 训练失败且本轮收到过快照时，可在本轮训练过程页查看已有上下文；重入后旧失败信息和快照必须清空。
- 训练结果页在当前实验尚未完成时展示清晰的空态，不引用历史记录中的详情。

## 7. 验收标准

1. 从准备页和历史页重新进入后，状态为等待训练，进度、快照、错误、指标、当前结果及选中步骤均为空。
2. 普通模型重入时不显示旧损失曲线、当前数据投影或旧分类结果。
3. CNN 重入时默认训练过程页为空；网络结构页仍能编辑已保留的网络配置。
4. 桌面实验流程只有配置栏和主画布两列，结果/解释可从主画布访问，主画布获得至少约三分之二的可用宽度。
5. 1366×768 桌面视口进入训练页后，训练画布卡片、图表与控制项无需内部滚动即可完整显示。
6. 窄屏无页面横向溢出，配置与主画布均可访问。
7. 历史记录及当前数据、模型、参数在重入后保留。
