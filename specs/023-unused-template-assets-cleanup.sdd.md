# SDD-023：清理未使用的模板资源

- 状态：已实现
- 编号：23
- 创建日期：2026-08-15

## 1. 背景与目标

项目初始化时保留了 Vite 与 React 模板资源。经全项目引用检索确认，这些文件未被应用、测试或文档使用。删除它们以减少仓库中的无效静态资源。

## 2. 范围

### 包含

- 删除 `src/assets/hero.png`。
- 删除 `src/assets/react.svg`。
- 删除 `src/assets/vite.svg`。

### 不包含

- 不删除仍被浏览器加载的 `public/favicon.svg`。
- 不修改应用代码、样式、构建配置或页面内容。

## 3. 用户流程

用户正常打开和使用网站，页面行为与资源清理前保持一致。

## 4. 技术方案

通过全项目文本检索确认三个候选文件没有引用后，直接删除其源文件。Vite 仅会打包被模块图引用的资源，删除无引用文件不影响产物。

## 5. 数据结构/API

无新增或变更的数据结构、API。

## 6. 错误处理

若构建阶段发现遗漏的静态资源引用，停止提交并恢复对应资源；本次通过构建验证引用完整性。

## 7. 验收标准

- 三个候选资源均从 `src/assets/` 删除。
- 全项目不包含对这三个文件的引用。
- 生产构建成功。

## 8. 测试策略

这是无引用静态资源清理，不新增自动化测试；通过 `npm run build` 验证编译和打包。
