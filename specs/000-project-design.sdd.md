# SDD-000：Web Deep Learning 总体设计与当前基线

- 状态：已实现基线；当前实现约束以本文件及后续功能 SDD 为准
- 版本：2.0
- 更新日期：2026-10-23
- 项目定位：面向初学者的浏览器端机器学习实验工作台

## 1. 背景与目标

项目让学习者在浏览器中完成数据选择、模型配置、训练观察、结果评估与实验回顾。目标是把常见机器学习概念变成可操作、可重复的小规模练习，而不是提供生产级训练平台。

产品闭环：

数据选择与检查 → 模型与参数配置 → Worker 训练 → 过程及结果可视化 → 本地保存、比较和报告导出

## 2. 当前产品范围

### 2.1 已实现功能

- 四类任务：分类、回归、聚类、降维。
- 分类模型：KNN、逻辑回归、线性 SVM、感知机、决策树、随机森林、AdaBoost、朴素贝叶斯、MLP、可视化 CNN。
- 回归模型：线性回归、岭回归。
- 聚类模型：K-Means、DBSCAN；降维模型：PCA。
- 五种合成二维表格数据、两种程序生成的 8×8 灰度教学图像。
- 简单 CSV 导入、数据预览与剖析、参数校验、可选训练/验证集划分。
- 浏览器 Worker 训练、训练过程快照、受支持模型的暂停/继续/单步、训练停止与取消。
- 任务结果、模型解释、交互预测、实验历史比较和 Markdown/HTML 报告。
- Dexie/IndexedDB 本地保存最近 20 条实验；支持 JSON 导入和导出。

### 2.2 明确范围外

- 登录、云端存储、后端训练、GPU/WebGPU 训练和协作分享。
- CSV 字段映射、类别特征编码、缺失值填补和通用预处理流水线。
- 真实图像导入、生产级 CNN、独立测试集、交叉验证、系统网格搜索。
- 大型数据处理或任何未经验证的生产性能承诺。

## 3. 用户与成功标准

主要用户为机器学习初学者、教师和需要快速演示算法行为的开发者。

教学成功标准：用户能载入小型样本、理解模型参数和训练单位、观察训练或结果可视化，识别评估数据来源，并保存及重新打开一次实验记录。指标必须标明数据划分口径，不把训练表现描述为泛化保证。

## 4. 技术架构

- React + TypeScript + Vite 负责界面与类型约束。
- Zustand 管理当前会话；Dexie/IndexedDB 保存实验记录。
- Papa Parse 读取简单 CSV；SVG、Canvas 与 ECharts 负责图形展示。
- Web Worker 执行训练，Worker 协议传递阶段、快照、控制和完成状态。
- 核心算法使用 TypeScript 教学实现，不依赖外部机器学习运行时。
- Vitest 覆盖单元/组件行为，Playwright 覆盖关键浏览器流程。

训练数据、结果和报告只保存在当前浏览器，用户可使用 JSON 文件手动迁移实验。

## 5. 数据约束

表格数据为有限数值特征和一个目标列。CSV 首行作为表头，默认最后一列为目标、其余列为特征；非法或缺失特征行跳过并报告。分类目标为类别标签，回归目标须为有限数值。没有交互式列映射或自动类别编码。

图像数据使用图像尺寸契约，目前仅内置合成 8×8 灰度样本。图像任务和表格任务不能混用。

## 6. 训练、评估与复现

- 相同数据、参数与随机种子应得到一致结果。
- Worker 训练不应阻塞界面；训练停止应结束当前 Worker，暂停/单步能力以算法真实支持为准。
- 分类和回归可选固定随机种子的训练/验证划分；默认关闭验证集，不提供独立测试集和交叉验证。
- 分类报告准确率、宏平均精确率/召回率/F1 和混淆矩阵；回归报告 MAE、MSE、R²。
- 实验记录保存数据、模型、参数、快照、指标、运行元数据和数据指纹；本地历史最多 20 条。
- 报告不包含代码版本和浏览器运行时版本，不能作为完整审计记录。

## 7. 页面与用户流程

1. 在“模型与数据”页选择任务、模型和内置数据或导入 CSV。
2. 查看样本、特征统计、类别分布和适用性提示，确认数据。
3. 在实验流程页调整模型参数并训练；符合能力声明的迭代模型可暂停、继续、单步，运行可停止或取消。
4. 查看训练过程、决策边界或任务结果，并使用交互预测。
5. 在历史记录中查看、比较、删除或导出实验。

所有面向用户的文字和文档使用中文。高维表格可训练，但可视化投影只展示部分维度，不代表完整空间边界。

## 8. 错误处理

CSV 结构不合法、有效样本不足、标签不合法、参数越界和 Worker 异常均应阻止错误训练并给出可读提示。浏览器存储失败时保留当前会话结果并明确提示，建议用户导出备份。

## 9. 验收标准

- 数据、模型、训练、结果、历史的关键流程在浏览器可完成。
- 参数设置与实际训练配置一致；相同随机种子可以复现随机算法结果。
- 指标明确显示训练集或验证集来源；缺失历史字段显示“未记录”。
- Worker 训练期间界面保持可交互，停止时不留下运行中的 Worker。
- JSON 导入经过校验，失败时不产生部分导入。
- 自动化测试、静态检查和生产构建在交付前通过。

## 10. 已知限制与风险

- 数据处理和训练适用于小规模教学实验；KNN、DBSCAN、树模型和边界绘制在大样本上成本较高。
- 自动预处理不足，特征尺度敏感的算法需要用户留意尺度差异。
- 只有可选验证集，没有独立测试集和交叉验证，调参结果可能过拟合。
- 合成图像与简化 CNN 不能代表真实图像任务。
- IndexedDB 存储受浏览器配额影响，且只保留最近 20 条记录。
