# SDD-013：模型选择与训练过程可视化优化

- 状态：已实现
- 创建日期：2026-08-09

## 1. 背景与目标

取消默认 KNN；补齐决策树、随机森林、朴素贝叶斯、AdaBoost、岭回归和 DBSCAN 的训练快照；训练中显示训练页签 loading。

## 2. 范围

- 初始和重置状态不选择模型，用户选择后才能训练。
- 六类模型输出带有限 `loss` 的快照，复用现有 Worker 和训练曲线。
- 训练页签在训练中显示旋转图标。

## 3. 用户流程

用户进入或重置工作台后模型为空；在模型页选择算法；开始训练时页签显示 loading；训练完成后恢复完成状态图标并展示曲线。

## 4. 技术方案

`ModelConfig.kind` 为可选；模型任务切换不自动选择算法；六类训练器按各自迭代/扫描阶段产生快照；布局根据训练状态渲染 CSS 旋转 loading。

## 5. 数据结构/API

- `ModelConfig = { kind?: ModelKind; params: Record<string, number> }`
- 快照包含有限 `loss`。

## 6. 错误处理

未选择模型时点击训练显示“请先选择模型”，不启动 Worker。

## 7. 验收标准

- 无默认模型，radio 初始均未选中。
- 六类模型快照非空且 loss 有限，训练曲线可展示。
- 训练中训练页签显示 loading，完成后消失。
- 测试、构建和 lint 通过。

## 8. 测试策略

覆盖 store、训练器、App 流程和布局；执行 `npm test`、`npm run build`、`npm run lint`。
