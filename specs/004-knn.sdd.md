# SDD-004：KNN 分类器

- 状态：Implemented
- 版本：1.0

## 背景与目标

提供最小可解释的 K 最近邻分类器，支持二维或任意维度数值特征，用于 MVP 决策边界和预测结果展示。

## 用户流程

1. 选择数据集并设置 `k`。
2. 调用训练器保存训练样本。
3. 对测试样本预测，按欧氏距离选取最近邻。
4. 使用分类指标评估结果。

## 技术方案

- 训练阶段不拟合参数，仅复制并校验样本和标签。
- 预测阶段计算平方欧氏距离，按距离升序取 `k` 个邻居。
- 多数投票；票数相同优先总距离小、再优先较近邻居出现顺序。
- `k` 必须为正整数；样本为空、维度不一致或出现非有限数值时拒绝训练。

## 数据结构

```ts
interface KnnModel {
  kind: 'knn'
  samples: number[][]
  labels: Label[]
  k: number
}
```

## 验收标准

- 线性分离样本可正确预测近邻类别。
- 训练至少发出一个 iteration=0 快照。
- 非法 `k` 抛出包含 `k` 的错误信息。
- 预测样本维度不匹配时抛出错误。
