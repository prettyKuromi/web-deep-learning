# SDD-022：CNN 构建器交互与训练面板布局

- 状态：Draft
- 编号：22
- 创建日期：2026-08-15

## 1. 背景与目标

现有可视化卷积神经网络将层编辑器放在左侧参数面板，同时训练过程卡片在 CNN 模式下高度不足，网络流图和训练控制可能被裁切。调整为以中间主面板完成网络搭建，并确保训练过程卡片完整展示内容。

目标是在不改变 CNN 训练算法、层校验规则或实验数据格式的前提下，提供直观的层新建、拖拽排序和就地参数编辑体验。

## 2. 范围

### 包含

- 选择 `visual-cnn` 时，左侧“参数配置”只显示学习率、轮数、批大小与随机种子等训练超参数，不再显示网络层编辑器。
- 中间训练画布区域显示 CNN 构建器：固定输入节点、可编辑层栈、固定 Softmax 输出节点，以及“新建层”入口。
- “新建层”可添加卷积、池化、全连接、激活和 Dropout 层。
- 每个可编辑层卡片直接显示并编辑其参数；支持鼠标拖放和键盘可操作的上移、下移、删除作为排序与无障碍回退方式。
- 拖放或编辑后继续复用既有层结构校验、输出形状和参数量计算；非法结构仍阻止训练并显示中文错误。
- CNN 模式下训练过程卡片使用适应内容的最小高度；网络构建区、网络流图、状态、控制按钮及错误消息均不可被裁切。页面保持固定视口，内容超高时仅训练过程卡片自身滚动访问。

### 不包含

- 修改卷积网络训练算法、层类型、层参数范围或默认网络。
- 自由连线、分支网络、外部拖拽库、保存新的 UI 布局状态。
- 修改非 CNN 模型的参数面板与训练流程。

## 3. 用户流程

1. 用户选择图像数据集和“可视化卷积神经网络”。
2. 左侧配置训练超参数；中间面板展示输入层、当前层栈和输出层。
3. 用户点击“新建层”选择层类型，或在层卡片中编辑参数。
4. 用户将层卡片拖到目标位置排序；无法拖放时可使用上移、下移按钮完成同一操作。
5. 构建器即时更新输出尺寸、参数量和错误提示；结构有效时可开始训练。
6. 训练期间，训练过程卡片完整显示网络流、状态与控制，内容不会被隐藏。

## 4. 技术方案

- 将 `VisualNetworkBuilder` 从 `SinglePageWorkbench` 左侧参数卡片移动到中间训练画布卡片；为其传入同一份 `layers`、`imageShape` 和 `onChange` 状态。
- 为层卡片实现原生 HTML5 Drag and Drop：拖动源与放置目标根据索引重排；不引入依赖。保留现有上移、下移按钮，提供拖拽失败和键盘用户的回退。
- 层卡片包含当前层名称、形状、参数量和本层编辑控件；新增层入口以轻量按钮菜单实现。
- 为 CNN 训练卡片添加专用布局类：取消会造成裁切的固定高度或隐藏溢出设置，使用 `min-height`、纵向内容流和窄屏媒体规则保证可见性。
- 训练画布中的网络流继续使用 `NetworkFlowCanvas`，置于构建器之后；不改变其数据接口。

## 5. 数据结构/API

复用 `VisualLayer`、`describeVisualNetwork(layers, imageShape, classes)` 与 `VisualNetworkBuilder` 的 `layers`、`imageShape`、`onChange` 接口。

`VisualNetworkBuilder` 新增的内部 UI 状态仅包含当前拖拽源索引，不写入实验配置。层顺序变化仍通过 `onChange(nextLayers)` 向上提交。

## 6. 错误处理

- 无法放置、拖到自身或层索引无效：不修改层顺序。
- 拖动结束未放置：不修改层顺序并清除拖动样式。
- 层参数非法、层顺序非法或尺寸无效：沿用现有即时错误消息和禁用训练逻辑。
- 小窗口高度或窄屏：页面不滚动，训练过程卡片内部滚动访问全部内容，不裁切控制与错误信息。

## 7. 验收标准

- CNN 模式的左侧参数配置不含卷积、激活等网络层编辑控件，只保留训练超参数。
- CNN 构建器位于中间主面板，包含输入、层栈、输出和“新建层”入口。
- 用户可以添加层、直接修改层参数、拖拽调整顺序；上移、下移、删除仍可用。
- 每次变更均即时更新形状、参数量与结构错误；非法结构不能开始训练。
- CNN 模式的训练过程卡片在常规与窄屏尺寸下不裁切网络构建器、训练流、按钮、状态或错误消息。
- 非 CNN 模型现有参数配置和训练图表保持不变。

## 8. 测试策略

- Vitest + React Testing Library：验证 CNN 构建器渲染在中间面板、左侧只出现训练超参数、添加与编辑层、拖拽重排、上移/下移回退及非法结构提示。
- CSS/组件测试：验证 CNN 训练卡片具有专用布局类且不使用导致裁切的固定高度规则。
- 运行 `npm test`、`npm run lint` 与 `npm run build`。
