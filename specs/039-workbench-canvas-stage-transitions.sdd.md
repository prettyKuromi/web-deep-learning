# SDD-039：工作台画布阶段转换

- 状态：草稿
- 编号：039
- 创建日期：2026-10-24

> 本规格仅定义工作台画布在网络结构、训练过程与结果之间的默认选择和自动转换。它对 SDD-037 中“CNN 重入默认训练页签”及“训练完成后仍留在训练页签”的行为作明确修订；SDD-037 的重入清理、布局、画布尺寸及其他要求继续有效。

## 1. 背景与目标

工作台目前对所有模型都默认显示训练过程页签。用户切换到可视化卷积神经网络（CNN）后，必须额外寻找并点击“网络结构”才能先了解或调整模型结构；重新进入实验以及重置后也没有依据当前模型选择最相关的画布阶段。训练成功时仍停留在训练过程页签，用户还要手动切到结果与解释才能查看本轮评估结果。

本功能使 CNN 实验进入工作台时默认先呈现网络结构，开始训练时切到训练过程，成功完成时自动呈现结果与解释。KNN、逻辑回归、线性 SVM 等非 CNN 模型保持训练过程作为默认页签。失败、停止或取消时不因终态自动跳离用户正在查看的训练上下文。用户始终可以手动访问可用页签。

## 2. 范围

### 包含

- 非 CNN 模型首次进入工作台时默认选中“训练过程”。
- CNN 模型首次进入、由其他模型切换到 CNN、重置或重新进入工作台时，默认选中“网络结构”。
- CNN 与非 CNN 之间切换模型时，画布默认选择随模型变化；同一模型下普通属性更新不覆盖用户手动选择的页签。
- 点击“开始训练”后选中“训练过程”，CNN 结构页仍可在训练期间通过页签访问。
- 训练正常完成时自动选中“结果与解释”。
- 训练状态为“训练完成，保存失败”时仍视为本轮训练完成；本轮首次从非完成态进入完成态时（无论是哪种完成状态）自动选中“结果与解释”。
- 用户可在训练完成后手动切回“训练过程”或 CNN 的“网络结构”；后续不相关的组件重渲染不得覆盖手动选择。
- App 将“训练完成”异步更新为“训练完成，保存失败”时视为同一完成态；若用户已在两次更新间手动切页，第二次状态更新不得再次切回结果页。
- 训练失败、停止或取消时不自动改变当前画布页签，保留用户当时的训练上下文。
- 结果与解释页在训练完成前仍可手动打开并显示既有未完成空态；只有本轮完成会自动切换到该页。
- 保留当前画布页签的键盘导航、无障碍语义及现有布局尺寸和响应式行为。

### 不包含

- 修改模型算法、训练状态机、训练参数、训练结果、数据集或持久化格式。
- 新增 CNN 架构编辑能力、训练能力、模型种类或数据导入格式。
- 改动工作台整体布局、训练图表、时间线、结果内容、间距标尺或卡片尺寸。
- 改变非 CNN 模型的默认页签或训练完成后自动显示结果的统一规则。

## 3. 用户流程

1. 用户进入实验工作台并使用非 CNN 模型时，主画布默认显示“训练过程”；若当前选择 CNN，主画布默认显示“网络结构”，让用户先查看/编辑模型结构。
2. 用户可以切换模型。切换到 CNN 后默认显示网络结构；切换到非 CNN 后默认显示训练过程。同一模型内的其他属性更新不强制更改用户手动选定的页签。
3. CNN 用户确认结构后点击“开始训练”，画布自动切回“训练过程”，开始展示本轮训练反馈；用户仍可切到“网络结构”检查配置。
4. 本轮训练首次从非完成状态进入完成态后（状态为“训练完成”或“训练完成，保存失败”），画布自动切换到“结果与解释”。用户可手动切回训练过程或 CNN 网络结构；若保存失败异步更新完成状态，该更新不再次抢回结果页。
5. 训练失败、停止或取消后，画布保持在该终态发生时用户正在查看的页签，以便继续查看训练上下文或修正网络结构。
6. 重置或重新进入实验工作台时，运行状态按现有 SDD-037 清理；画布默认阶段依据当前模型重新选择：CNN 为网络结构，其他模型为训练过程。

## 4. 技术方案

- 在 `SinglePageWorkbench` 中按模型初始化画布页签：`visual-cnn` 选择网络结构，其他模型选择训练过程。模型标识确实变化时重新选择其默认阶段；不得在每次父组件重渲染时重置用户选择。
- 重置训练时按当前模型应用默认阶段。开始训练入口仍显式选择训练过程，然后调用现有训练回调。
- 对训练完成状态作单向 UI 阶段转换：只有状态从非完成态首次进入 `训练完成` / `训练完成，保存失败` 这一完成态类别时，才进入结果与解释。`训练完成` 与 `训练完成，保存失败` 之间的状态更新仍属同一轮完成，不重复切页；训练失败、训练已停止、训练已取消及其他非完成状态不触发自动跳转。
- 完成态内的状态更新和无关属性更新均不得覆盖用户已手动选择的页签。
- 保持现有画布页签可见性条件、非 CNN 对网络结构页签的访问限制、键盘导航、tab/tabpanel 的无障碍关系及现有 CSS 布局。
- 不新增状态管理依赖、公共 API 或持久化字段；仅修改画布页签状态协调逻辑和对应测试。

## 5. 数据结构与接口

- 不新增持久化字段、Worker 消息或公共接口。
- 复用 `SinglePageWorkbench` 内部 `CanvasView`（`training | results | architecture`）、现有模型标识与训练状态字符串。
- 模型默认阶段映射：`visual-cnn → architecture`；其他模型（包括未选择模型）`→ training`。
- 完成态类别：`训练完成 | 训练完成，保存失败`；仅首次进入该类别映射到 `results`。同类状态值互转不构成新的阶段边沿。训练失败、训练已停止、训练已取消不映射到其他页签。

## 6. 错误处理

- 保存实验记录失败但训练已成功时，继续展示完成状态及本轮结果；若此前已从训练曲线/网络结构手动离开结果页，不得因保存失败状态更新再次切回结果页。
- 训练失败、用户停止或取消时，不自动覆盖当前页签，确保用户可以继续查看失败信息、训练过程或 CNN 网络结构。
- 未完成状态下手动打开结果页时沿用现有空态提示，不展示历史实验详情或未完成的旧结果。
- 模型页签不可用时沿用既有页签约束，不产生无效选中状态；键盘导航仍只遍历当前可用页签。

## 7. 验收标准

1. 首次渲染非 CNN 模型（或未选择模型）时，“训练过程”被选中；首次渲染 CNN 模型时，“网络结构”被选中并展示当前网络画布。
2. 从非 CNN 切换到 CNN 后默认选中网络结构；切回非 CNN 后默认选中训练过程。模型未变化的属性重渲染保留用户手动选择的页签。
3. CNN 重置后和重新挂载进入工作台后默认选中网络结构；非 CNN 重置或重新挂载后仍默认选中训练过程。
4. 从任一可用阶段点击“开始训练”后选中训练过程；训练过程中可手动切到 CNN 网络结构。
5. 本轮状态首次从非完成态进入“训练完成”或“训练完成，保存失败”时自动选中结果与解释。用户随后手动切回训练过程或网络结构后，即使状态从“训练完成”更新为“训练完成，保存失败”，或其他属性重渲染，选中状态仍保持。
6. 训练失败、训练已停止、训练已取消时不自动改变发生终态前选中的页签。
7. 未完成时用户手动打开结果与解释仍得到现有空态；上述状态变化不改变现有页签键盘导航和无障碍关系。
8. 不改变画布布局、尺寸、响应式行为及非 CNN 可用页签集合。
9. 在真实浏览器以 1366×768 和 390×844 视口走查 CNN 的网络结构、训练过程、结果与解释页以及非 CNN 训练过程页；确认阶段切换后卡片尺寸与间距舒适、内容无裁切或重叠，390px 下页面无横向溢出且配置和画布可访问。若无需改 CSS，实施记录须写明现有样式已通过这两种视口核对。

## 8. 测试策略

- 在 `src/features/workbench/SinglePageWorkbench.test.tsx` 使用 React Testing Library 覆盖默认模型映射、CNN/非 CNN 切换、同模型重渲染保留手动选择、CNN/非 CNN 的重置与卸载重入、开始训练切回训练过程。
- 使用 `rerender` 将状态从训练中更新为终态，分别验证“训练完成”和“训练完成，保存失败”会自动选择结果与解释；验证完成后手动切回可用页签且普通属性重渲染不覆盖手动选择。
- 验证保存错误顺序：先由“训练中…”更新为“训练完成”并确认自动选结果，再手动切到训练过程或 CNN 网络结构，随后更新为“训练完成，保存失败”；断言手动选择保持且结果内容仍可查看。
- 对训练失败、训练已停止、训练已取消，先手动选定训练过程或 CNN 网络结构，再更新状态并断言页签保持。
- 保留并运行同文件中的现有键盘导航、未完成结果空态、CNN 结构可编辑、训练开始行为测试。
- 在真实浏览器以 1366×768 桌面和 390×844 窄屏核对 CNN 网络结构、训练过程、结果页以及非 CNN 训练过程页；检查阶段切换前后卡片边界、间距、文字/控件裁切及页面横向溢出。若未改样式，在实现记录中注明原有样式已通过视觉核对；若发现问题，先更新本规格再调整样式。
- 验证命令：`npm.cmd test -- src/features/workbench/SinglePageWorkbench.test.tsx`、`npm.cmd test`、`npm.cmd run build`、`npm.cmd run lint`、`git diff --check`。真实浏览器核对按本节所列视口与流程进行；不为本功能新增浏览器测试基础设施。
