# 工作台交互与样式细修

## 背景与目标
当前深色工作台存在数据预览和全局状态不同步、导航缺少禁用反馈、训练终态仍可操作、普通卡片嵌套滚动和中等屏幕裁切问题。以现有功能为基础改善可靠性、可读性和空间利用，不重做视觉风格。

## 范围
- 数据集确认状态随实际修改失效；确认后仅返回数据集页不失效。导航以禁用状态、说明文字提供反馈。
- CSV 读取或解析错误时禁止确认；重新选择内置数据或成功导入后恢复。返回页面保留真实数据及 CSV 标识。
- 运行、暂停和终态分别约束训练按钮；删除无 Worker 时伪造快照的单步逻辑；无损失数据依据真实状态显示说明。
- 预览数值最多四位小数，悬停保留原值。普通适用性说明使用中性样式，模型名单按需展开；风险仍用警告样式。
- 页面统一纵向滚动，普通卡片不截断；保留中等屏幕两栏、窄屏单栏以及 CNN 图必要的横向滚动。
- 参数滑块与数值输入同一行；中文标签、百分比指标和历史选中状态统一。
- 不删除当前已实现的算法，不新增依赖、不修改算法或 e2e。

## 用户流程
1. 初次进入数据页，实验流程禁用并提示先确认数据。
2. 选择合法数据后确认，进入实验页；返回但未修改可直接再次进入，修改后需重新确认。
3. 导入无效 CSV 后确认按钮禁用，重新选择合法数据可恢复。
4. 选模型后训练：运行时可暂停或停止，暂停时可单步、继续或停止，结束后仅可重新开始或重置。
5. 查看结果和历史，指标中文且使用百分比，当前查看记录有清晰选中反馈。

## 技术方案
- App 维护确认与导入有效状态，DatasetPanel 通过有效性回调告知读取/错误状态；数据本身由现有 Store 保持。
- DatasetPanel 懒初始化默认数据，仅使用一份当前数据；预览由 useMemo 派生，CSV 选项明确展示。
- TrainingProgressChart 新增可选 status，区分空数据、运行、暂停、停止、失败和已完成，不能仅凭无 loss 宣称训练完成。
- 使用自然内容高度与页面纵向滚动，网格子项 min-width:0，指标自动换列；CNN 图局部横向滚动保持。
- 仅用现有 React、CSS、Vitest 实现。

## 数据结构/API
- DatasetPanelProps 新增 onValidityChange?: (valid: boolean) => void；action 支持按有效状态渲染。
- TopLevelNavigationProps 新增 workflowDisabled?: boolean，提供 title、disabled 与邻近说明。
- TrainingProgressChartProps 新增 status?: string；旧调用仍可展示空数据/真实损失曲线。
- 不改变实验存储、Worker 消息及算法结果结构。

## 验收标准
- 未确认或修改数据后无法进入流程；确认后返回未修改可进入。
- CSV 错误后无法确认，重新合法选择/导入恢复；CSV 预览与下拉标识一致。
- 训练完成/停止后继续、单步、停止禁用，不再生成虚假快照；非迭代完成显示已完成拟合。
- 375、768、1366、1920 宽度无页面横向溢出，普通预览、解释、结果不截断，CNN 图可读。
- 数字最多四位小数且 title 保存原值；中文指标统一百分比，历史选中状态可识别。
- npm test、npm run lint、npm run build 通过。

## 测试策略
- App 行为测试覆盖确认导航、返回保留、修改失效、CSV 错误恢复。
- DatasetPanel 覆盖 CSV 状态、格式化及默认预览同步。
- 工作台和训练图覆盖运行/暂停/终态控制及无损失数据的状态说明。
- 完整运行单元测试、lint、构建；主代理使用 Playwright 验证布局和完整流程。
