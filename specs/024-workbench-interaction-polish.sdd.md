# SDD-024：工作台交互与布局细节修复

- 日期：2026-10-16
- 状态：实现与验证中

## 背景与目标

实际浏览器操作发现数据预览与训练上下文不同步、未确认步骤缺少反馈、训练完成后仍可继续或单步，以及卡片高度限制导致的裁切和多层滚动。目标是保留现有深色风格，改善初学者完成一次实验时的可理解性与可读性。

## 范围

- 数据确认状态、CSV 导入错误与恢复、页面往返时的预览一致性。
- 训练运行、暂停、完成、失败与停止的控件状态及过程提示。
- 375、768、1366、1920px 的布局、卡片高度与滚动策略。
- 模型解释对比度、参数输入、指标中文文案、数据精度、历史选中状态。
- 不添加算法、账号、服务或依赖。现有树模型、MLP、聚类等已经实现，保留实际支持的模型；模型兼容性说明改成按需展开。

## 用户流程

1. 初次进入先看到当前真实数据预览，实验流程 Tab 禁用并展示确认提示。
2. 确认合法数据后进入实验流程；返回数据页而未修改时保留确认状态。更改数据或导入失败后需要重新确认。
3. CSV 正在解析或解析失败时无法确认；重新导入合法文件或选择内置数据恢复。CSV 显示当前导入项，不冒充某个内置数据集。
4. 选择模型后训练；运行时可暂停、停止，暂停时可单步、继续或停止；终态可重新开始或重置，不能伪造进度。
5. 完成后查看模型解释、指标和决策边界；历史记录清楚标记当前查看项。

## 技术方案

- 继续使用 App 和 Zustand 的数据，不增加状态库；数据集面板接收当前数据和有效性回调，确认状态由 App 管理。
- 导航使用真正 disabled 属性及中文说明；训练控制从实际状态派生，单步只向活动 Worker 发送命令。
- 无损失曲线时根据状态显示等待、运行、暂停、终止或拟合完成，避免把缺失损失当成完成。
- 普通内容随页面自然纵向滚动，配置和解释卡片按内容确定高度；保留 CNN 网络图必要的局部横向滚动。
- 中等桌面配置与训练分两栏，结果在下方；窄屏一栏。指标响应式网格，SVG 根据容器缩放。
- 预览数字最多四位小数，原始值保留在 title；正常模型适用说明采用中性色，实际风险使用警告色。

## 数据结构/API

- 扩展数据面板与数据页 Props 以接收当前数据和数据有效状态。
- 导航 Props 增加实验流程可用状态；图表 Props 增加训练状态。
- 不改变 Dataset、实验存储格式、Worker 通信协议或算法参数。

## 验收标准

- 默认预览与确认后的训练数据名称、样本一致；返回页面保持真实内置或 CSV 状态。
- 无效 CSV 和解析过程中不能确认；未确认时 Tab 提示原因，未选模型时训练按钮禁用。
- 完成/失败/停止后继续、单步、暂停、停止禁用；无 Worker 时单步不会新增快照。
- 无迭代模型完成时不再出现“暂无训练过程数据”或“第 0 次迭代”。
- 四种目标宽度均无页面横向溢出，普通解释和结果卡片不裁切；隐藏上传控件不扩大页面。
- 用户文案中文、表格数值可扫描、模型解释符合深色对比度、历史指标统一百分比且选中状态明确。

## 测试策略

- Vitest 覆盖数据确认失效、CSV 错误恢复、页面往返、训练状态、无 Worker 单步、数值格式。
- Playwright 实际执行主流程、CSV 恢复与往返、训练终态和四种宽度的溢出/裁切检查；检查 CNN 以防破坏原有编辑流程。
- 验证命令：`npm test -- --run`、`npm run lint`、`npm run build`、`git diff --check`。
- 默认 Playwright 浏览器未安装时可通过临时配置复用本机 Chrome，不将本机绝对路径写入项目配置。
