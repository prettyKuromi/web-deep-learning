# SDD-032：实验运行元数据与报告导出

## 背景与目标

历史记录虽能保存模型和快照，但实际 seed、耗时和数据身份没有稳定写入，比较页面只能显示“历史记录未保存”。补充真实运行元数据，并支持导出一份面向复盘的实验报告。

## 范围

- 每次训练记录开始/结束时间、耗时、模型 seed、Worker 确认的训练单位、完成或停止状态、数据集 fingerprint 和评估配置。
- 用户停止训练时保存真实结束时间、耗时、已收到的部分快照和配置，记录明确标为不完整停止运行；不伪造最终模型、预测或指标。
- fingerprint 对规范化特征/标签/数据集名计算确定性摘要；不可用时明确标记。
- fingerprint 计算不可用或失败不得把已成功训练标为训练失败；运行结果和记录仍保留。
- 历史比较显示真实元数据和分类、回归、聚类、PCA 任务适用指标。
- 支持导出 JSON 实验包和可读 Markdown/HTML 报告，包含参数、数据样本/特征规模、训练单位、训练曲线数据，以及标明来源和样本数的训练/验证指标、评估配置和限制说明。
- 停止运行的详情和报告明确显示停止状态及没有最终结果，不渲染或伪造训练结果面板。
- 旧记录兼容，缺失字段不补造。

## 验收标准

- 训练完成或停止后元数据状态、训练单位、结束时间和耗时真实；停止记录保留已有快照且无最终模型/预测/指标；相同数据内容 fingerprint 一致。
- fingerprint 不可用或计算抛错时仍保留成功训练结果，并明确显示指纹不可用。
- 导出报告可独立阅读并标记训练/验证口径、投影限制和缺失字段。
- Markdown/HTML 报告和比较显示数据规模、训练单位、评估配置、训练/验证来源及样本数，并按分类/回归/聚类/PCA 展示适用的真实指标；缺失指标不显示为 0。
- 历史详情明确标记停止记录，不渲染伪造的最终结果。
- 导出失败给出中文错误且不影响当前训练结果。

## 测试策略

Vitest 覆盖 fingerprint、元数据生成和报告序列化；组件测试覆盖导出按钮和缺失字段；Playwright 验证完成一次训练后导出报告。

## 实现状态

- 状态：运行元数据和报告导出已开始实现；本轮评估要求的停止记录、完整任务指标和失败隔离按下述验证命令完成后再更新。
- 实现内容：训练完成记录真实开始/结束时间、耗时、seed、数据 fingerprint 和评估来源；历史页支持导出 Markdown/HTML 报告，缺失字段显示未记录。
- 验证命令：`npm test -- --run`；`npm run build`；`npm run lint`。
- 已知限制：浏览器端不记录代码版本；报告不替代完整实验审计系统。
