# SDD-007：Neon Lab 科技感界面

- 状态：Implemented
- 编号：007
- 创建日期：2026-08-08

## 1. 背景与目标

当前工作台使用浅色卡片布局，缺少机器学习实验环境的科技感和视觉层级。本功能将 UI 调整为 Neon Lab 深色实验室风格，使数据、模型、训练和结果更像一个高级的浏览器端 ML 实验工作台，同时不改变现有训练和数据功能。

## 2. 范围

### 包含

- 深海蓝背景、网格纹理、青色高光和半透明面板。
- 顶部实验室标识、运行状态和实验元信息。
- 左侧纵向实验流程与控制面板。
- 右侧决策边界主视觉、指标摘要和状态条。
- 640px 以下单列响应式布局、键盘可见焦点和现有中文文案。

### 不包含

- 不改变数据集、KNN 算法、训练 API 或图表数据计算。
- 不增加第三方依赖和复杂动效。

## 3. 用户流程

用户进入页面后从左侧流程选择数据集，设置 KNN 的 k 值并点击训练；训练状态和完成结果在左侧状态区与右侧结果区同步展示，决策边界图保持当前数据集和预测结果。

## 4. 技术方案

在 `App.tsx` 保留现有状态和事件处理，仅调整语义结构、状态标签和布局 className；在 `App.css`、`index.css` 中集中定义 CSS 变量、深色背景、面板、流程步骤、图表容器及响应式规则。使用伪元素和渐变实现轻量网格和光晕，不引入运行时动画库。

## 5. 数据结构/API

不新增数据结构或 API。继续使用 `workbenchStages`、`DatasetPanel`、`DecisionBoundaryChart` 和 `createKnnTrainer` 现有接口。

## 6. 错误处理

保留 `DatasetPanel` 的错误消息和训练状态文本；错误状态使用橙红色高亮，不能因视觉调整隐藏或截断可理解的中文提示。

## 7. 验收标准

- 页面整体呈现 Neon Lab 深色科技风格，主色为青色，卡片层级清晰。
- 四个实验阶段可见且当前阶段有明显高亮。
- 数据集控制、KNN 参数、训练按钮、训练状态、决策边界和结果摘要均可操作/可见。
- 640px 以下页面单列，控件不溢出；按钮和输入有可见焦点态。
- 现有单元测试、构建命令通过。

## 8. 测试策略

- 运行 `npm run test -- --run` 验证现有行为。
- 运行 `npm run build` 验证 TypeScript 和 Vite 构建。
- 使用 Playwright 或浏览器手工检查桌面与窄屏布局、阶段切换和训练状态显示。
