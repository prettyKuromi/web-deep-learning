# SDD-020：沉浸式实验工作台 UI 重构

- 状态：已实现
- 编号：020
- 创建日期：2026-08-14

## 1. 背景与目标

现有界面在常见桌面视口中会产生页面级纵向滚动，数据集确认操作、模型参数和训练过程被推到首屏之外；历史记录详情区域顶部留白过多，详情按钮悬停时又出现不清晰的白字。整体视觉缺乏机器学习实验工作台应有的状态感与层次。

目标是将应用改为固定视口的沉浸式实验界面：页面本身不滚动，内容过长时由卡片内部滚动；通过深色实验舱、网格背景、青紫强调色和清晰的训练状态建立技术感，同时不改变训练、数据和持久化逻辑。

## 2. 范围

### 包含

- 桌面端将根应用固定为 `100dvh`，禁用 `body` 级纵向滚动。
- 头部、一级导航和当前页面组成固定高度工作区；数据集、实验流程、历史记录均在工作区内布局。
- 数据集页改为左右两栏：左侧选择与导入，右侧可独立滚动的数据预览；确认按钮固定在左侧操作区，无需滚动页面。
- 实验流程改为固定高度三栏：左侧配置、中央训练、右侧洞察。参数区、训练时间线和解释结果按需内部滚动。
- 历史记录改为同屏列表与详情；详情面板紧贴顶部开始展示；“查看详情”悬停保持深色文字与高对比边框/底色。
- 重整卡片、间距、按钮、输入控件、滚动条和焦点态，保留中文界面文本与无障碍语义。
- 为固定工作区结构、数据集操作可见性、历史详情按钮状态补充测试。

### 不包含

- 不修改训练算法、Worker、数据格式、实验持久化和业务流程。
- 不新增第三方 UI 依赖、主题切换、账户或远程服务。
- 不承诺在窄屏移动端完全无页面滚动；窄屏改为可读的纵向降级布局。

## 3. 用户流程

1. 用户打开数据集选择页，可在首屏完成内置数据集选择或 CSV 导入，并直接点击确认进入实验流程；数据预览独立滚动。
2. 用户进入实验流程，在同一视口内看到配置、训练和洞察三栏；调整较多参数时仅左侧卡片滚动。
3. 用户训练时在中央查看状态、曲线和操作按钮；训练记录多时仅时间线滚动。
4. 用户进入历史记录，点击左侧任一记录的“查看详情”，右侧从顶部立即显示指标和图表；列表与详情互不推动。

## 4. 技术方案

- 在 `index.css` 建立深色设计令牌，令 `html`、`body`、`#root` 以固定高度承载应用。桌面端 `body` 使用 `overflow: hidden`。
- 在 `App.css` 将 `.app-shell` 设为三行网格（头部、导航、内容），并使内容区域 `min-height: 0; overflow: hidden`。
- `DatasetPage` 增加工作区分栏包装，复用 `DatasetPanel` 的现有逻辑；CSS 将预览区放入可滚动卡片。
- `SinglePageWorkbench` 使用明确的 `single-page-workbench--immersive` 容器和列内滚动区，保留现有回调及 aria 标签。
- `HistoryPage` 继续复用 `ResultsPage`，通过选中记录 ID 为列表项增加视觉选中态；详情面板使用顶端对齐的滚动容器。
- 以 CSS 为主完成视觉重构，避免引入复杂状态和额外组件。

## 5. 数据结构与接口

- `HistoryPageProps` 新增可选 `selectedId?: string`，仅用于渲染当前记录的选中态。
- `App` 向 `HistoryPage` 传入当前 `selectedId`。
- 其他数据结构、训练回调、持久化接口保持不变。

## 6. 错误处理

- 保持现有数据集导入错误、训练错误与模型未选择提示。
- 交互控件禁用态仍可通过视觉和原生 `disabled` 属性识别。
- 内部滚动容器保留 `overscroll-behavior: contain`，避免滚动链传播至页面。

## 7. 验收标准

- 在宽度至少 1024px、高度至少 720px 的桌面视口，`html` 和 `body` 不产生纵向页面滚动条。
- 数据集确认按钮在数据集选择页的左侧操作区可见，数据预览内容过长时只滚动预览区域。
- 实验流程在桌面端同屏显示三栏；参数、训练时间线、洞察内容分别独立滚动。
- 历史记录列表和详情同屏，详情面板顶部无额外大留白。
- “查看详情”在悬停/聚焦时保持可读的深色字体，具有明确边框或背景反馈。
- 现有单元测试、静态检查、构建及可用的 Playwright 流程通过。

## 8. 测试策略

- Vitest：验证数据集页的沉浸式工作区入口、实验流程三栏根容器、历史记录当前项选择态以及详情操作按钮。
- CSS/结构检查：验证根应用和各页面含固定工作区 class，防止回归为页面级堆叠布局。
- 完整验证：`npm test -- --run`、`npm run lint`、`npm run build`、`git diff --check`、`npm run e2e`（浏览器环境可用时）。

## 9. 实现记录
