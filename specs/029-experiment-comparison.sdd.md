# SDD-029：历史实验比较与复现信息

## 背景与目标

历史页目前以单条记录查看为主，不支持并排分析调参结果。为开发者和初学者提供有限数量实验的横向比较，帮助识别参数和评估指标的差异。

## 范围

- 历史列表支持选择 2 至 4 条实验进入比较。
- 并排呈现模型、数据集、参数、随机种子、样本/特征信息、训练耗时和适用指标。
- 可比较时叠加训练损失趋势；无曲线的算法说明原因。
- 明确标记数据集、任务、划分或指标来源不同的实验，不将不可比指标伪装成同口径。
- 兼容旧实验；新增复现元数据字段为可选。
- 不新增云端同步、自动调参或统计显著性分析。

## 用户流程

用户在历史记录中选中两至四个实验，打开比较视图，检查共同信息和差异。可返回历史列表调整选择，或打开任一实验详情。

## 技术方案

在历史页内增加比较选择与独立比较区域，复用现有 ExperimentRecord、结果指标和快照，不改变持久化存储策略。比较组件通过统一字段适配器生成表格行；仅当训练单位和损失定义相同时叠加曲线，否则分开标注。

## 数据结构/API

ExperimentRecord 新增可选 `runMetadata`：

```ts
interface RunMetadata {
  seed?: number
  startedAt?: number
  completedAt?: number
  durationMs?: number
  datasetFingerprint?: string
  evaluation?: EvaluationConfig
}
```

缺失字段展示“历史记录未保存”，不推断或伪造。

## 验收标准

- 只能选择 2 至 4 条记录；数量不足或超过上限时有明确状态。
- 不同模型、数据集、指标来源清楚标记；无共同曲线时仍能比较参数和指标。
- 有共同训练单位与损失语义的曲线可叠加并包含图例。
- 旧记录缺少元数据时正常显示且不崩溃。
- 选择与比较区域在窄屏可滚动使用。

## 测试策略

- Vitest 覆盖比较适配器、可比性判断和旧记录。
- 组件测试覆盖选择上下限、移除选择、比较表和曲线可用性。
- Playwright 用两次不同参数训练验证历史比较操作。

## 未决问题

- 一次比较上限为 4 条，避免小屏和图表信息过载。
- 数据集 fingerprint 使用规范化数据与标签的 SHA-256；若浏览器 Web Crypto 不可用则标记不可用。

## 实现状态

- 状态：已实现历史记录比较与响应式布局。
- 实现内容：历史记录支持 2–4 条选择、移除、指标/模型/数据集/种子/耗时并排比较；旧元数据显示“历史记录未保存”；只有同数据集、同模型且快照损失完整时叠加曲线；窄屏比较表支持横向滚动。
- 验证命令：`npm test -- --run`（28 个测试文件、177 项通过）；`npm run build`；`npm run lint`。
- 已知限制：当前比较界面主要展示分类指标，回归/聚类指标仍需按任务扩展；完整历史比较 Playwright 场景待补。
