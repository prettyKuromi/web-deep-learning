# SDD-016：单页训练工作台与模型专属过程可视化

- 状态：已批准，开发中
- 创建日期：2026-08-09

## 1. 背景与目标

当前工作台将数据、模型、训练和结果分散在多个页面/标签，用户难以建立“配置—训练—观察—解释”的连续认知。参考 TensorFlow Playground 的单页实验体验，本功能将核心流程收敛到单页三栏工作台，并为复杂模型展示具有教学意义的训练内部过程。

## 2. 范围

### 包含

- 单页三栏布局：左侧实验配置，中间训练主画布，右侧模型解释与结果。
- 核心配置、训练控制和训练状态同屏展示；高级内容使用展开/收起。
- 训练控制：开始、暂停、单步、继续、停止、重置。
- 通用训练快照、节流刷新和关键轮次回放。
- 重点模型专属可视化：
  - MLP：层结构、节点激活、连接权重、前向传播样例、loss/accuracy、决策边界。
  - 逻辑回归：权重、概率面/决策边界、loss/accuracy。
  - 线性 SVM：权重、间隔、支持向量、边界、hinge loss。
  - 决策树/随机森林/AdaBoost：树结构、当前分裂路径、分裂规则、集成/弱学习器贡献。
- 其他现有模型（KNN、朴素贝叶斯、K-Means、DBSCAN、PCA）提供统一训练时间线、结果画布和基础指标，不强行增加复杂内部动画。
- 复用现有 Dataset、Worker、实验 JSON/IndexedDB 和随机种子机制；保留旧路由作为兼容入口，默认进入新工作台。

### 不包含

- 新增算法、后端服务、账号体系、云端训练、GPU/WebGPU。
- 图像/CNN、文本/RNN/Transformer。
- 自动发布或第三方服务接入。

## 3. 用户流程

1. 用户进入工作台，看到数据集、模型选择、参数和训练按钮。
2. 用户选择数据集与模型并调整参数；不满足训练条件时，在对应区域显示中文原因。
3. 用户开始训练，中间画布实时显示进度、耗时、loss/等价指标、训练/验证曲线和数据投影。
4. 用户可暂停、单步、继续或停止；时间线保留关键快照，可回看历史状态。
5. 训练完成后，中间画布保留最终过程，右栏展示模型专属解释、指标、混淆矩阵和预测样例。
6. 用户可重置、保存或导出实验，旧实验数据仍可导入。

## 4. 技术方案

- 新增通用 `TrainingSnapshot`，包含 step/epoch、loss、metrics、画布数据、模型解释数据和时间戳。
- Worker 消息协议扩展为快照流；主线程使用节流策略更新图表，避免高频渲染阻塞。
- 使用模型类型到“解释面板数据”的纯函数映射，组件只负责渲染，避免在页面中耦合算法细节。
- 单页布局复用现有组件与 CSS 变量，使用 CSS Grid；窄屏自动堆叠为单列。
- 二维数据显示真实决策边界；高维数据显示 PCA/特征投影，并明确“仅投影展示”。

## 5. 数据结构/API

```ts
interface TrainingSnapshot {
  step: number
  epoch?: number
  loss?: number
  metrics: Record<string, number>
  chart?: { points?: number[][]; labels?: Array<string | number>; boundary?: number[][] }
  explanation?: Record<string, unknown>
  timestamp: number
}
```

现有 `Dataset`、`ModelConfig`、Worker 训练消息和持久化格式保持向后兼容；新增字段均可选。

## 6. 错误处理

- 未选择模型、数据为空、特征/标签不匹配、非法参数、类别不足、Worker 训练异常均显示可理解的中文提示。
- 无法形成有效验证集时回退训练集指标，并在结果区域说明。
- 停止训练后 Worker 必须终止或忽略后续消息，保留已生成快照。

## 7. 验收标准

- 进入工作台即可在同一页面看到数据、模型、参数、训练和结果区域。
- 重点模型在训练中产生可回看的专属快照；简单模型至少有统一训练时间线和结果画布。
- 暂停/单步/继续/停止/重置状态正确，训练不阻塞主线程。
- 相同数据、参数和 seed 的快照与结果一致。
- 二维边界、高维投影、指标和错误提示可见且文案为中文。
- 现有实验 JSON/IndexedDB 数据可继续使用。

## 8. 测试策略

- Vitest：快照生成与序列化、训练控制状态、模型解释映射、组件关键交互。
- 算法测试：重点模型固定 seed 的快照序列一致性。
- Playwright：选择数据—模型—训练—查看过程—查看结果的主流程，以及窄屏布局。
- 验证命令：`npm test -- --run`、`npm run build`、`npm run lint`。

## 9. 实现状态、验证命令与已知限制

- 实现状态：开发中。
- 验证命令：待实现后补充实际结果。
- 已知限制：首期重点模型的专属解释以教学可视化为主，不承诺研究级逐样本归因；高维图表仍是投影而非真实高维决策边界。
