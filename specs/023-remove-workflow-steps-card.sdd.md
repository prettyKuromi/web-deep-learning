# SDD-023：移除实验步骤卡片

- 状态：Draft
- 编号：23
- 创建日期：2026-08-15

## 1. 背景与目标

单页工作台左上角的“实验步骤”卡片占用了有限的固定视口高度，与左侧“实验配置”和中间“当前数据集”信息重复。移除该卡片，为参数配置释放空间，同时保持用户了解当前数据集与模型的必要上下文。

## 2. 范围

### 包含

- 从单页工作台左侧移除“实验步骤”卡片及其四个步骤状态。
- 删除只为该卡片服务的状态计算、DOM 和样式。
- 左侧保留“实验配置”和模型参数卡片；中间保留“当前数据集”栏及更换数据集操作。
- 保持桌面端固定视口与现有 CNN 训练卡片内部滚动行为。

### 不包含

- 更改模型选择、参数编辑、训练控制、数据集切换或结果展示行为。
- 调整三列工作台的列宽或新增替代导航。

## 3. 用户流程

1. 用户进入实验工作台，左侧直接看到“实验配置”。
2. 用户在左侧选择模型和编辑参数。
3. 用户通过中间的“当前数据集”栏确认或更换数据集。
4. 用户继续在中间面板构建 CNN 或控制训练。

## 4. 技术方案

- 从 `SinglePageWorkbench` 删除 `workflowSteps` 派生数组和 `<nav className="workflow-steps">`。
- 删除 `SinglePageWorkbench.css` 中仅用于步骤卡片的 `.workflow-steps*` 与 `.workflow-step*` 规则。
- 将 `single-page-config` 网格行简化为标题和参数卡片两行，保留参数卡片的内部滚动策略。
- 更新组件测试，移除对步骤导航的断言，继续验证当前数据集栏与其他核心布局区域。

## 5. 数据结构/API

不新增或修改数据结构、组件属性和外部接口。

## 6. 错误处理

不改变既有错误处理。数据集切换、模型兼容性和训练错误仍由原有组件处理。

## 7. 验收标准

- 页面不再出现“实验步骤”卡片、步骤导航或步骤状态。
- 左侧仍显示实验配置、模型选择与参数编辑。
- 中间“当前数据集”栏和更换数据集操作仍可用。
- 桌面端保持固定视口；CNN 模式下仍仅训练卡片内部滚动。
- 非 CNN 模型的工作台布局和训练控制不受影响。

## 8. 测试策略

- 使用 React Testing Library 验证步骤导航不存在，实验配置、训练画布、模型解释与当前数据集栏仍存在。
- 运行 `npm test`、`npm run lint`、`npm run build`。
