# SDD-022：网站图标替换

- 状态：已实现
- 编号：22
- 创建日期：2026-08-15

## 1. 背景与目标

将默认浏览器标签页图标替换为用户提供的 Web Deep Learning SVG，使网站标识符合项目主题。

## 2. 范围

### 包含

- 覆盖 `public/favicon.svg`。
- 保持 `index.html` 对 `/favicon.svg` 的既有引用不变。

### 不包含

- 不修改页面 Logo、主题样式或其他静态资源。
- 不清理 `src/assets` 中现有 SVG。

## 3. 用户流程

1. 用户打开网站。
2. 浏览器加载 `/favicon.svg` 并显示新图标。

## 4. 技术方案

Vite 会原样提供 `public/` 目录的文件。因此只替换同名图标文件，避免调整 HTML 资源路径。

## 5. 数据结构/API

无新增数据结构或 API。继续使用：

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />
```

## 6. 错误处理

若浏览器继续显示旧图标，强制刷新以清除图标缓存；应用功能不受影响。

## 7. 验收标准

- `public/favicon.svg` 为提供的 64 × 64 图标。
- `index.html` 继续引用 `/favicon.svg`。
- 生产构建成功。

## 8. 测试策略

纯静态资源替换，按用户要求不新增或运行自动化测试；执行 `npm run build` 验证生产构建。
