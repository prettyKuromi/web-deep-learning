# SDD-001：实验工作台壳层

- 状态：Implemented
- 编号：001
- 创建日期：2026-08-08

## 1. 背景与目标

为 MVP 提供单页实验工作台的基础导航和模块占位，使用户能理解“数据集 → 模型 → 训练 → 结果”的主流程。

## 2. 范围

包含四阶段导航、当前阶段状态、项目模块卡片和中文欢迎说明。不包含真实训练交互、图表和实验持久化。

## 3. 用户流程

用户打开页面后看到实验流程，点击阶段按钮可切换当前阶段，页面保留清晰的模块占位信息。

## 4. 技术方案

React 函数组件与本地状态实现；阶段名称和顺序集中定义在 `src/app/workbenchTypes.ts`，避免 UI 中散落魔法字符串。

## 5. 数据结构与接口

```ts
type WorkbenchStage = '数据集' | '模型' | '训练' | '结果'
const workbenchStages: WorkbenchStage[]
```

## 6. 错误处理

当前壳层无外部输入和异步操作，不需要专门错误处理。

## 7. 验收标准

- 页面显示四个阶段，顺序固定。
- 点击阶段后当前阶段状态更新。
- 页面使用中文，并说明后续模块正在接入。
- `workbenchTypes` 有单元测试。

## 8. 测试策略

使用 Vitest 验证阶段常量；后续补充 Playwright 验证点击流程。

## 9. 实现记录

- 实现状态：已完成基础壳层
- 验证命令：`npm run test -- src/app/workbenchTypes.test.ts`
- 已知限制：模块卡片仍是占位内容。

## 10. 未决问题

真实工作台布局和各模块交互由后续 SDD 定义。
