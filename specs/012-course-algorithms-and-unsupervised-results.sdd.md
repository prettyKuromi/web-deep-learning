# SDD-012：课程基础算法扩展与无监督结果展示

- 状态：进行中
- 创建日期：2026-08-08

## 1. 背景与目标

修复 PCA 训练后缺少过程与结果的问题，并补充大学机器学习课程中常见的基础算法。默认启动模型继续保持 KNN，不增加默认模型自动切换。

## 2. 范围

- PCA：输出可观察的迭代/计算快照、主成分、方差解释率和投影预览。
- 分类扩展：随机森林、AdaBoost、多项式逻辑回归。
- 回归扩展：多项式回归、Lasso 回归。
- 聚类扩展：DBSCAN、高斯混合模型、层次聚类。
- 任务分组页继续按分类、回归、聚类、降维展示。

## 3. 约束

- 仍使用二维数值特征和浏览器端 Worker。
- 默认数据集、默认模型和默认参数不改变；默认模型仍为 KNN。
- 非分类任务不得调用分类指标或决策边界组件。

## 4. 验收标准

- PCA 训练页至少显示两个过程快照或明确的计算阶段，并显示结果摘要。
- PCA 结果包含主成分数量、方差解释率和样本投影预览。
- 新算法可在模型页按任务类型选择，并通过 Worker 完成计算。
- KNN 默认启动和原有分类流程保持不变。
- `npm test`、`npm run build`、`npm run lint` 全部通过。
