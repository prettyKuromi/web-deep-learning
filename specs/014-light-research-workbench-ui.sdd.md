# SDD-014：明亮研究工作台视觉改版

- 状态：Implemented
- 编号：014
- 创建日期：2026-08-09

## 1. 背景与目标

当前界面采用深色 Neon Lab 风格，科技感强但学习内容的阅读层级、留白和图表可读性仍有提升空间。本次改版采用“明亮研究工作台”方向，保留现有训练流程和交互，仅调整视觉层级、色彩、间距与响应式布局，使页面更接近 TensorFlow Playground、W&B 和 Colab 等机器学习工具的研究型界面。

## 2. 范围

### 包含

- 暖白背景、深墨文字、蓝紫主强调色。
- 顶部产品栏、实验状态和导航视觉优化。
- 工作流步骤、卡片、表单、按钮、指标和图表容器统一为轻量研究台样式。
- 保留现有中文文案、组件结构、训练逻辑和响应式断点。

### 不包含

- 不新增模型、数据集、持久化接口或第三方依赖。
- 不改变训练算法、状态结构和页面路由行为。

## 3. 用户流程

用户进入工作台后，在明亮背景下按“数据集 → 模型 → 训练 → 结果”完成实验；顶部可快速识别当前运行状态和实验记录入口；操作卡片与结果图表保持清晰的左右层级。

## 4. 技术方案

- 仅修改 `src/index.css` 与 `src/App.css` 的设计令牌和布局样式。
- 复用现有 className，避免修改 React 组件和业务状态。
- 使用 CSS 变量统一颜色、阴影、边框和圆角；使用浅色图表容器提升可读性。
- 保持 640px、900px 现有响应式断点，并让窄屏内容自动单列。

## 5. 数据结构/API

无变化。

## 6. 验收标准

- 页面整体呈现明亮研究工作台风格，背景、卡片和文字对比度适合连续阅读。
- 工作流步骤、数据集、模型参数、训练状态、结果指标和图表均清晰可见。
- 现有交互测试通过，页面可构建，窄屏布局不出现横向溢出。

## 7. 测试策略

- `npm run test -- --run`
- `npm run build`
- `git diff --check`
- 使用 Playwright/浏览器检查桌面和窄屏页面截图与关键文案。

## 8. 实现状态、验证命令和已知限制

- 实现状态：已完成 CSS 视觉改版。
- 验证命令：`npm run test -- --run`（16 个测试文件、85 个测试通过）；`npm run build`（Vite 构建通过）；`git diff --check`（通过）。浏览器检查确认页面背景为 `rgb(244, 246, 251)`、主标题和中文流程内容正常、无横向溢出。
- 已知限制：图表 canvas 的内部主题仍由现有组件控制，本次只调整其外层容器。
- E2E 限制：Playwright 自动启动被已有本地 Vite 进程占用端口阻塞，已使用现有 `http://127.0.0.1:5173` 服务完成浏览器级检查。
