# SDD-040：工作台操作引导与帮助

- 状态：导航入口与浮层调整待评审与实现
- 编号：040
- 创建日期：2026-10-25

## 1. 背景与目标

工作台面向机器学习初学者，包含任务与模型选择、数据确认、模型参数、训练控制、结果解释和实验历史。用户第一次进入时可能不知道推荐顺序、控件何时可用、操作会造成什么变化，也可能难以理解模型参数和评估指标。

本功能建立贯穿工作台的操作引导与帮助体验，让用户在当前页面理解实验流程、关键控件及其状态，并能随时重新查看说明。提示依据当前任务、模型、画布阶段和训练状态提供内容。帮助面板以可关闭的非模态浮层覆盖局部页面，不改变下方工作区的布局位置。

## 2. 范围

### 包含

- 在工作台主导航栏最右侧提供持续可访问的“操作说明”入口。打开非模态帮助面板，优先展示当前页面及当前实验阶段相关说明，并可访问完整流程。
- 在“模型与数据、实验流程、历史记录”三个主页面各提供一条简洁、可收起的情境提示，说明当前页面用途和推荐下一步；同一页面同时最多显示一条。
- 引导覆盖选择任务和模型、选择并检查数据、确认进入实验、配置和启动训练、观察及控制训练、阅读结果、回顾与比较历史的完整路径。
- 帮助上下文区分实验画布的“网络结构、训练过程、结果与解释”视图，并随用户切换、开始训练和训练完成等既有阶段变化更新内容，不额外弹出提示。
- 对含义不直观的按钮、图标控件、状态相关操作和关键模型参数提供就近说明，解释用途、可用条件、操作结果或参数影响。清晰的文字按钮不重复增加说明。
- 对上下文禁用的关键操作显示可理解的原因。训练控制说明根据当前模型的真实训练能力和运行状态变化。
- 提示由用户通过“我知道了”收起；每条提示使用稳定标识并在当前浏览器保存收起状态。帮助面板始终可重新查看所有说明，并提供恢复提示的操作。
- 说明使用中文；支持鼠标、键盘焦点和触屏，不依赖悬停作为唯一帮助入口。
- 引导只解释操作和概念，不替用户改变任务、模型、数据、参数或训练状态。

### 不包含

- 新增键盘快捷键、算法、训练能力、数据格式、账号、云端服务或遥测。
- 模态式强制导览、自动操作工作台、视频课程、测验或独立的课程管理系统。
- 改变现有工作流顺序、页面导航、训练状态机、Worker 协议、实验数据和持久化格式。
- 重复实现 SDD-024 的错误恢复、SDD-026 的真实训练过程反馈或 SDD-035 的训练能力提示可见性。

## 3. 用户流程

1. 用户首次打开“模型与数据”页时看到一条引导卡，了解任务入口和推荐实验顺序；可直接操作、收起提示或打开“操作说明”。
2. 用户选择模型和数据集。关键参数、图标控件和上下文禁用操作可从附近获取用途、条件和预期结果；简单、标签清晰的按钮不增加冗余帮助文字。
3. 用户确认数据并进入“实验流程”。页面引导卡说明配置与训练；帮助面板依据当前模型、训练能力和画布视图显示对应内容。开始训练、完成训练或切换画布视图时，面板上下文同步更新，不抢焦点或自动弹出新提示。
4. 用户在结果视图查看当前任务的指标含义、评估数据来源和解释限制；在历史记录页查看记录选择、比较、导入和导出说明。
5. 用户点击“我知道了”后，相应页面提示在本地记为已收起。提示未收起时，离开后再次进入仍显示同一张卡片，不重复叠加或创建新通知；重置训练不清除偏好。
6. 用户随时可从主导航栏右侧的“操作说明”重新阅读帮助，或恢复已收起的页面提示。帮助面板覆盖在页面内容上方，打开和关闭不推动下方工作区；点击面板外部会关闭面板并继续执行原点击，焦点不被抢回入口。

## 4. 技术方案

- 新增轻量的工作台帮助面板和情境提示组件，中文内容集中维护，并按页面、画布视图、任务/模型、训练能力和训练状态选择说明。
- 主导航栏采用左侧页面标签、右侧紧凑的“操作说明”入口；情境提示独立显示在导航栏下方，不与帮助入口共用一行。
- 页面提示固定为模型与数据、实验流程、历史记录各一条。实验流程内部的网络结构、训练过程和结果说明由当前帮助面板上下文提供，避免每切换一个画布视图就显示新的卡片。
- `SinglePageWorkbench` 通过内部回调向 `App` 提供当前画布视图，使帮助面板能响应用户切页及既有自动阶段转换；该回调仅用于本地界面上下文。
- 引导偏好使用版本化 `localStorage` key 保存已收起的稳定提示标识。文案编辑保留原标识；新增提示使用新标识；偏好结构升级应迁移已收起标识，不因普通升级重置用户选择。格式损坏时忽略损坏数据并恢复默认提示。
- 帮助面板采用锚定在主导航“操作说明”入口附近的非模态浮层，不占文档流高度，不显示遮罩，也不锁定页面焦点。打开后焦点留在入口；入口通过 `aria-expanded` / `aria-controls` 关联面板，DOM 顺序保证从入口按 Tab 后首先进入面板的关闭按钮；Shift+Tab 可返回，Tab 可继续离开面板。Escape 或关闭按钮关闭后焦点还给入口；点击面板外部时关闭面板并让原点击继续生效，不把焦点移回入口；页面上下文变化后如面板仍打开则显示最新内容。浮层有足够高的层级，尺寸限制在视口内，长内容在面板内滚动；不得覆盖入口自身。
- 对训练控制的实际能力说明以 `TrainingCapability`、训练状态和现有能力提示为唯一事实来源，不维护第二套模型能力清单。
- SDD-024 已有的导航禁用原因和错误恢复继续作为对应状态的现有说明。对于其他关键禁用操作，若当前页面没有可见原因则新增简短原因；`title` 只作补充，不作唯一来源。
- 同一控件在同一视图中只出现一份主要说明。现有能力提示已完整说明当前能力时，帮助面板不再复制同一段提示；用户显式打开帮助后可提供更完整、互补的背景说明。
- 操作引导视觉沿用工作台的深色卡片和青蓝强调色，以 `src/App.css` 中的 `.single-page-card` / `.workbench-page-card` 和 `src/index.css` 中的颜色变量为样式基准。主导航左侧显示页面入口，最右侧显示紧凑的“操作说明”入口；页面提示独立放在导航栏下方。帮助面板作为入口附近的浮层覆盖在内容上方，不推动页面；当前章节有清楚的视觉重点，其他章节便于快速浏览。按钮、边框、文字层级和焦点样式复用现有主题变量，不使用白底默认控件，不新增图标或样式依赖。
- 提示文案优先占据剩余宽度并正常折行；“我知道了”和“操作说明”入口保持紧凑，不被挤压或拉伸。窄屏时导航标签与帮助入口仍在同一导航栏中，帮助入口固定靠右且不挤掉标签；提示卡在导航栏下方占用自己的空间。面板章节窄屏单列。浮层可以覆盖下方局部内容，但不能改变工作区位置/尺寸、盖住帮助入口或超出视口；不添加遮罩，点击浮层外部关闭并继续原操作。
- 提示正文与按钮在深色表面上需容易辨读；键盘焦点沿用 `src/index.css` 的全局青色 `:focus-visible` 描边，确保描边清晰且不被裁切。验收同时检查正文、按钮常态/悬停/焦点状态。
- 结果帮助根据当前任务显示对应指标说明：分类包括准确率、宏平均精确率/召回率/F1 和混淆矩阵；回归包括 MAE、MSE 和 R²；聚类说明簇数、噪声标签及结果的含义；降维说明 PCA 投影和已记录的解释方差。数据来源只读取当前结果或历史记录中的评估来源；缺失时显示“未记录”，不得推断。
- 不增加状态管理依赖、网络请求、后端 API、实验持久化字段或训练代码。

## 5. 数据结构与接口

- 新增内部页面上下文：`setup | workflow | history`；工作流页面另携带 `training | results | architecture` 画布视图。
- 帮助内容按需读取只读上下文：页面、画布视图、任务、模型、训练状态和 `TrainingCapability`。
- 本地偏好格式：`{ version: 1, dismissedHintIds: string[] }`，使用独立、带版本号的 localStorage key。后续结构升级需保留可识别的 `dismissedHintIds`。
- 每页引导卡有稳定提示标识；普通文案修改不改变标识，新增提示分配新标识。
- 帮助组件使用内部 Props，不新增 App 公共业务 API；新增的画布视图回调仅供工作台内部 UI 使用。
- 不改变 Dataset、训练配置、Worker 消息和实验记录格式。

## 6. 错误处理

- localStorage 不可用或写入失败时，在当前会话内仍可收起和查看提示；不阻塞导航、训练或帮助入口。
- 偏好数据损坏或未知格式时安全回退到默认提示，不产生未捕获异常。
- 某个模型没有特定控制能力时，帮助内容只说明它实际支持的操作；不显示暂停、单步等不存在的建议。
- 当前上下文没有专属说明时，帮助面板显示完整流程和可访问的其他章节，不显示空白面板。
- 帮助面板作为非模态浮层覆盖局部内容，不推动页面布局；面板外点击会关闭浮层并继续原操作，焦点保持在用户点击目标上。浮层不盖住入口，限制在视口内并为长内容提供内部滚动。关闭按钮和 Escape 关闭后焦点返回入口；焦点可按正常页面顺序进出面板，不设置焦点陷阱。

## 7. 验收标准

1. 首次访问三个主页面时分别显示对应的一条引导卡，且每个页面最多一条；提示在桌面和窄屏均不遮挡主要内容或操作。
2. 未收起的提示在页面离开并返回后仍为同一张卡片，不重新弹出通知；收起后重入、训练重置和普通刷新均不自动显示；从帮助面板恢复后可重新显示。
3. 主导航栏最右侧的“操作说明”入口始终可访问；面板显示当前页面相关内容及完整流程说明。面板以入口附近的浮层显示，打开和关闭不改变下方工作区的位置或尺寸，且不遮住入口自身。
4. 工作流帮助内容随“网络结构、训练过程、结果与解释”画布视图、当前模型、任务及训练状态更新；CNN 结构视图和开始训练/训练完成后的自动画布转换均展示相符说明，且切换不自动弹出提示或抢焦点。
5. 代表性控制能力覆盖：KNN 等不支持暂停/单步的拟合模型不显示这些操作建议；逻辑回归等支持控制的迭代模型在训练中、暂停和停止状态显示的说明与 `TrainingCapability` 一致。
6. 分类、回归、聚类、降维结果分别显示适合其任务的指标解释；分类和回归明确指出计算数据来源，历史记录缺失来源时显示“未记录”，不推断验证集或泛化表现。
7. 对关键上下文禁用操作可看到具体原因；重要图标控件和参数说明可通过鼠标、键盘焦点或触屏操作访问，且同一视图不重复展示相同说明。
8. 键盘用户可从主导航帮助入口 Tab 进入面板关闭按钮及内容、继续 Tab 离开；在入口或面板内按 Escape 均可关闭并让焦点停在入口；帮助面板没有焦点陷阱。
9. localStorage 缺失、抛错、数据损坏及旧偏好格式均不影响应用使用；旧结构可迁移时保留已收起提示。
10. 在 1366×768 和 390×844 浏览器视口检查模型与数据、实验流程、三个画布视图及历史记录；帮助面板可访问、页面无横向溢出，提示不覆盖控件或重要结果。
11. 现有导航、数据确认、训练控制、画布页签和结果行为不变。
12. 操作提示、帮助入口和帮助面板沿用工作台深色卡片与主题变量；帮助入口位于主导航最右侧，提示独立位于导航下方，面板当前章节、其他章节和操作按钮具有清楚层级。使用最长页面提示文案检查：正文保留可读空间，操作按钮不挤压文案。
13. 在 375×812、390×844、768×1024、1366×768 浏览器视口检查模型与数据页的提示排布和导航栏；窄屏下页面标签与紧凑帮助入口保持在同一导航栏且无溢出，文字、按钮状态与键盘焦点在深色表面上清晰可见。
14. 在四种视口下打开帮助面板时，下方工作区位置与尺寸保持不变，浮层盖在内容上方并始终完整位于视口内；点击面板外部会关闭浮层并继续原操作，不显示遮罩、不产生焦点陷阱，长内容在面板内部滚动。
15. 面板通过 `aria-expanded` / `aria-controls` 关联帮助入口，Tab 顺序从入口进入关闭按钮和面板操作后再离开；点击外部关闭时不把焦点抢回入口，Escape/关闭按钮关闭时焦点返回入口。
