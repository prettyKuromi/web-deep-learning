# SDD-034：模型与数据集合并选择

- 状态：已实现并验证
- 编号：034
- 创建日期：2026-10-22

## 1. 背景与目标

当前顶层导航将模型选择和数据集选择拆成两个步骤。模型选项以较大的纵向卡片显示，占据独立页面；用户选完模型后还要切换页面才能看到数据选择与预览。本功能将两类选择合并到“实验准备”页，以紧凑控件选择模型和数据集，并在同一页面查看数据预览，减少空白和步骤切换。

## 2. 范围

### 包含

- 将顶层流程收敛为“模型与数据 → 实验流程 → 历史记录”。
- 在同一准备页显示任务类型、具体模型、数据集选择、CSV 导入与数据预览。
- 用任务类型选项和紧凑模型下拉框替代纵向的大尺寸模型选项卡片；仅显示当前选中模型的简短说明。
- 继续按模型筛选可选内置数据集，并保留模型与数据类型的兼容性约束。
- 保留数据确认、导入状态、数据错误、特征预览截断和实验流程进入条件。
- 为宽屏、窄屏和移动视口调整准备页布局。

### 不包含

- 修改模型算法、参数、训练结果、实验持久化格式或 CSV 解析规则。
- 增加新的数据集、模型、页面或运行时依赖。
- 改变训练流程和历史记录功能。

## 3. 用户流程

1. 用户进入“模型与数据”页，在任务类型中选择类别，并从紧凑选择框中选择模型。
2. 同页数据集选择会按模型限制为兼容的数据类型；表格模型可选择内置表格数据或导入 CSV，`visual-cnn` 只能选择图像数据。
3. 用户在同页预览数据集统计、适用性提醒和样本；模型选择和数据预览不需要跨页查看。
4. 用户确认有效数据集后进入实验流程；训练中仅禁用会改变模型或数据配置的“模型与数据”页，实验流程和历史记录仍可切换。
5. 用户从实验流程点击“更换数据集”返回同一“模型与数据”页。

## 4. 技术方案

- `TopLevelPage` 收敛为 `setup | workflow | history`；导航显示“模型与数据”“实验流程”“历史记录”。
- 新增或整合一个实验准备页组合组件，将任务和模型选择放入数据控制区上方，继续复用 `DatasetPanel` 的数据选择、CSV 导入和预览能力。
- 模型选择使用任务类型按钮与具体模型 `<select>`，保留当前模型的一句简短说明；不再渲染纵向全量模型说明卡片。
- 准备页任务类型标签使用单一 Tab 停靠点；左右方向键在可用标签间循环移动，Home/End 聚焦首/末标签，并选择该任务的首个模型。禁用标签跳过，鼠标选择行为保持一致。
- 数据预览继续位于准备页主区域。桌面布局由控制区和预览区两栏组成，控制区可独立纵向滚动；窄屏恢复自然纵向页面流，让模型、数据选择和确认操作完整可达，再向下查看预览，避免嵌套滚动和横向溢出。
- 复用现有 `handleModelSelection`：更换为不兼容模型时切换到兼容的默认数据；若当前 CSV 或内置数据兼容新模型则保留。准备页需确保 `DatasetPanel` 能反映 App 中因模型切换而变更的数据。
- 数据有效性和导入过程仍由 `datasetConfirmed`、`DatasetImportState` 管理。确认按钮在导入中或有错误时禁用；导航只允许在有效确认后进入实验流程。
- 使用现有 React、CSS 和组件，不增加依赖；无需改动训练 Worker 或实验数据格式。

## 5. 数据结构与接口

- `TopLevelPage` 从 `model | dataset | workflow | history` 改为 `setup | workflow | history`。
- 顶层导航移除分别控制模型页和数据页的禁用状态，只保留训练配置锁定及实验流程确认状态。
- 实验准备页接收当前模型及模型变更回调、当前数据和数据变更回调、导入状态、数据有效性回调与确认回调；复用现有 `Dataset`、`DatasetImportState` 和 `ModelKind`。
- 如需同步模型切换时 App 侧重置的数据，扩展 `DatasetPanel` 对外部当前数据变更的同步；不新增持久化字段或 Worker 消息。

## 6. 错误处理

- 非法 CSV、读取中断和导入等待状态沿用现有中文提示；遇到这些状态不能确认并进入实验流程。
- 更换模型后若数据不兼容，切换到对应类型的内置默认数据，并同步预览；兼容数据不应被意外重置。
- `visual-cnn` 不显示 CSV 入口；没有兼容数据或数据无效时，确认按钮不可用。
- 小屏由页面自然纵向滚动，保证选择控件、确认操作和数据提示完整可达；样本表格可在自身区域横向滚动。
- 训练中切换到历史记录再返回实验流程时，必须保留本轮运行 ID、训练状态、快照及控制能力，不得因重新进入流程而重置或取消训练；若用户请求返回模型与数据页，则保持配置页锁定。

## 7. 验收标准

1. 主导航依次只有“模型与数据”“实验流程”“历史记录”，不存在独立模型页和数据页。
2. 模型类型、具体模型、数据集选择、CSV 入口和数据预览能在同一准备页访问。
3. 模型选择不再使用占据大段纵向空间的整行说明卡片；模型说明仅在当前选择附近展示。
4. `visual-cnn` 只可选择图像数据且没有 CSV 入口；其他模型可选择表格数据与 CSV，图像数据不会出现在其选择项中。
5. 切换到不兼容当前数据的模型后，默认数据和预览同步切换；兼容模型切换保留已有数据，包括有效 CSV。
6. 数据导入中、导入失败或数据无效时不能确认；有效数据确认后可进入实验流程。
7. 实验流程中的“更换数据集”返回合并后的准备页；模型和数据仍显示实际当前值。
8. 桌面与窄屏下选择控件和预览均可访问，无横向溢出或被裁切的确认操作；已有训练、CNN 与历史流程不回归。
9. 训练运行期间“模型与数据”页禁用，但可在实验流程与历史记录间切换；从历史记录返回实验流程后，本轮训练继续并保留已有运行状态与停止控制。
10. 准备页任务类型标签可用左右方向键循环、Home/End 跳至首/末项；每次键盘移动均同步选中任务、首个模型及模型下拉框；禁用标签不会获得焦点，鼠标选择仍正常。

## 8. 测试策略

- Vitest/Testing Library：验证新的三项主导航、模型与数据同页呈现、模型与数据兼容筛选、切换模型时的数据同步、CSV 状态、确认门槛及返回准备页行为。
- 页面测试：覆盖准备页任务类型标签的 Tab 停靠点、左右方向键循环、Home/End 跳转、焦点与模型同步、禁用项跳过，以及现有鼠标选择行为。
- App 测试：在受控 Worker 运行中切换到历史记录并返回，验证配置页锁定、实验流程可返回且运行 ID、快照和控制不重置。
- 运行受影响的页面、DatasetPanel 与 App 测试，再运行项目测试、lint、build 和 `git diff --check`。
- 浏览器验证至少覆盖桌面与窄屏；执行“选择模型 → 选择/导入数据 → 确认 → 实验流程 → 更换数据”流程，并检查无横向溢出。
