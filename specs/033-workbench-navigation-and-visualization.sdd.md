# SDD-033：工作台流程与可视化体验改进

- 状态：实施中
- 编号：033
- 创建日期：2026-10-22

## 1. 背景与目标

当前工作台把数据集放在模型之前，页面主体会随内容增长而整体滚动；训练配置、网络结构编辑和模型结果的视觉权重也不均衡。历史记录主要依赖按钮操作，难以快速切换和删除记录。本次改进按用户反馈重排流程，并让主要工作区固定在视口内、各内容面板独立滚动，使训练网络和结果图表成为页面重点。

## 2. 范围

### 包含

- 固定应用顶部品牌区，将品牌眉题改为 `web-deep-learning` 并提高文字清晰度。
- 调整主流程为“模型选择 → 数据集选择 → 实验流程”，数据页按已选模型筛选内置数据集，并在流程内隐藏当前数据不兼容的模型。
- 缩窄数据选择控制区、固定两侧面板高度；预览在右侧独立滚动，特征统计最多展开 8 维并注明剩余维度数。
- 训练页不产生整页滚动；配置、训练画布、模型解释与结果分别在自己的面板内滚动。配置栏提供开始训练按钮，训练画布获得主要宽度。
- 删除独立 CNN 网络搭建器；在实际网络数据流节点上编辑层参数、选择激活函数、拖拽排序，并通过层前/后的加号菜单插入层。
- 为 CNN 增加一套确定性 8×8 图形图像数据集，使用现有 `visual-cnn` 训练器和图像尺寸契约。
- 解释准确率、精确率、召回率、F1 与损失的含义；无迭代损失时显示数据散点/已完成结果，而不是大块空白。
- 历史页固定在视口内，列表和详情独立滚动；点击整张记录卡片即可查看，卡片悬停/键盘聚焦时显示删除按钮；参数使用中文名称和结构化展示。
- 将历史页的 JSON 导入/导出及已有报告导出操作放到页面标题右侧；移除“删除当前”全局按钮。

### 不包含

- 新增训练模型、改动训练算法、改变持久化/导入导出的数据格式。
- 将图像训练或 CSV 解析移出浏览器；CNN 仍只接受带尺寸信息的图像数据集。
- 移动端专属页面或新的图表依赖。

## 3. 用户流程

1. 用户先在模型选择页选任务类型和模型，然后进入数据集选择页。
2. 数据集页只列出该模型可用的内置数据；表格模型可导入 CSV，图像 CNN 只列图像数据。选择或导入数据后确认并进入实验流程。
3. 实验流程左侧调整参数并开始/暂停/停止训练；中间查看损失曲线或 CNN 网络结构，CNN 层在网络节点上直接编辑、插入和拖拽排序；右侧查看模型解释和结果指标。
4. 训练器没有记录迭代损失时，中间区域仍显示数据分布或最终结果图。
5. 用户进入历史记录后可点击任意卡片查看详情；悬停/聚焦卡片并点击叉号删除该记录；导入、导出操作位于页面标题右侧。

## 4. 技术方案

- 根布局采用视口高度网格：品牌头部、主导航固定占行，应用内容填充剩余空间并裁切外层溢出。桌面与窄屏均由具体面板承接纵向滚动。
- 顶层导航加入模型选择页并调整次序。`ModelPage` 在尚未选数据时展示全部模型；数据页接收 `ModelKind` 并据 `isModelCompatible` 过滤数据集；实验页的模型列表和任务类别也根据当前数据兼容性过滤。
- `DatasetPanel` 以模型兼容性生成可选内置集合；CNN 隐藏表格 CSV 入口。统计列表和样本表限制到前 8 个特征，完整维度仍保留在数据和训练流程中。
- 扩展内置数据集为 `shapes`：使用种子生成五类 8×8 灰度几何图形，保持 `Dataset.dataType === 'image'` 与单通道 `imageShape`，不改变 `visual-cnn` 接口。
- `NetworkFlowCanvas` 接收 `outputClasses`、层更新回调和图像尺寸，作为 CNN 唯一的网络编辑界面。每个用户层节点显示插入前/后的菜单；层本身支持拖放和现有范围校验。固定输入/输出节点不参与排序。
- 训练画布优先按现有迭代快照绘制损失。无可绘制损失时显示二维特征投影；训练完成后把结果组件放大到主画布，结果侧栏保留模型解释与指标。
- 分类指标附中文说明（宏平均口径与计算含义）；历史记录通过 `onDelete(id)` 精确删除，卡片点击与其内部复选框/删除按钮事件分离。
- 使用现有 React、SVG/ECharts 和 CSS；不增加运行时依赖。

## 5. 数据结构与接口

- `TopLevelPage` 增加 `model`，导航顺序为 `model | dataset | workflow | history`。
- `DatasetPage`、`DatasetPanel` 增加可选 `model: ModelKind`；模型为 `visual-cnn` 时只暴露图像数据集，其他现有模型暴露表格数据集。
- `BuiltinDatasetId` 增加 `shapes`；数据结构仍为 `Dataset`，图像尺寸为 `{ width: 8, height: 8, channels: 1 }`，标签为 `0–4`。
- CNN 画布接口包含 `layers`、`imageShape`、`outputClasses`、`status`、`snapshots` 和 `onChange(layers)`。网络结构及训练结果 JSON 保持原结构。
- 历史页删除接口调整为 `onDelete(recordId: string)`；原有 JSON 与 Markdown/HTML 报告导出接口保留。

## 6. 错误处理

- 选模型后若当前数据不兼容，重置为该模型可用的默认内置数据；用户进入数据页后仍可选择同类型的其他数据。
- CNN 的 CSV 入口不显示；无可用内置数据时给出清晰提示，不允许继续训练。
- 网络层参数越界或结构无效时保留节点错误说明，并禁用开始训练；添加/拖拽层时不静默修正用户输入。
- 删除失败沿用历史页错误提示；删除操作只针对被点击卡片的 ID。
- 高维数据预览只截取展示，不改变实际训练特征；图表注明只展示前两个特征的投影。

## 7. 验收标准

1. 应用头部留在固定视口区域；品牌眉题显示 `web-deep-learning` 且字形清楚。
2. 顶层流程顺序是模型、数据集、实验流程、历史记录。
3. 选 `visual-cnn` 后数据页只呈现图像数据集且不显示 CSV 上传；选择其它现有模型时不显示图像数据集。
4. 实验页不出现禁用态的不兼容模型选项，也不允许切换到无兼容模型的任务类别。
5. 数据集控制栏比预览区窄，内容高度固定；右侧预览可单独滚动。64 维数字/图形数据的统计与样本表最多展示 8 维并说明截取范围。
6. 桌面训练页外层无滚动条；配置、训练和结果面板各自可滚动。开始训练按钮在配置栏，训练画布宽于配置栏。
7. CNN 页面不渲染 `visual-network-builder`；网络数据流节点直接提供参数/激活函数编辑、拖动排序和前后插入层操作，结构校验会反馈错误。
8. CNN 可选择数字和图形两种图像数据集，两者均可开始训练；图形数据在固定随机种子下可复现。
9. 训练曲线缺少损失值时，中间区域出现二维投影或最终结果可视化；结果指标有可访问的中文 tooltip，解释宏平均与含义。
10. 历史列表和详情独立滚动；整张记录卡片可选中；卡片删除按钮只在悬停或键盘聚焦时显现；训练参数以易读名称/值呈现。
11. 历史页 JSON/报告操作在标题右侧，不再显示“删除当前”；每条记录的叉号删除只移除该条。
12. 相关单元测试通过，生产构建通过；由独立子代理打开内置浏览器逐页验收并记录关键视口滚动、流程筛选、CNN 插层和历史卡片交互结果。

## 8. 测试策略

- 使用 Vitest/Testing Library 验证：图形图像数据种子一致与结构有效、模型/数据集筛选、特征预览截断、CNN 画布插层/更新/排序/错误提示、无损失结果回退、指标 tooltip、历史卡片点击/删除和标题操作。
- 运行相关测试后运行 `npm test` 与 `npm run build`，按项目验收约定记录实际命令和结果。
- 浏览器验收检查至少 1440×900 桌面和窄视口：页面外层无滚动，面板内部可滚动；顺序完成模型→数据集→训练，CNN 结构编辑可见；历史卡片选择/删除和导入导出工具栏位置正确。
