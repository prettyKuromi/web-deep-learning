# SDD-017：三页实验工作台布局

- 状态：设计已确认，待实现
- 编号：017
- 创建日期：2026-08-09

## 1. 背景与目标

当前首页使用四列工作台布局，数据集选择与预览栏、实验配置栏重复渲染 `DatasetPanel`，造成内容重复、主训练区域被压缩，也削弱了“先准备数据，再观察训练与结果”的用户流程。

本功能将工作台调整为三个页面：数据集选择、实验流程、历史记录。数据集选择独立成页；实验流程页将训练过程与结果作为核心内容，并让模型参数位于左侧；历史记录独立浏览，不与当前实验配置混杂。

## 2. 范围

### 包含

- 顶部三步导航：`数据集选择`、`实验流程`、`历史记录`。
- 数据集选择页：内置数据集、CSV 导入、数据摘要和预览。
- 实验流程页：左侧模型与参数、中部训练过程和主结果、右侧指标与模型解释。
- 历史记录页：实验列表、只读详情、JSON 导入/导出入口及删除确认。
- 允许从实验流程返回数据集页更换数据集。
- 更换数据集后保留模型参数，清空当前训练快照、指标、当前结果和选中实验详情，并提示需要重新训练。
- 保留当前未保存实验状态：在三个页面之间切换时不丢失合法的当前配置和训练状态。
- 响应式布局：宽屏三栏，中等屏幕结果下移，窄屏单列。

### 不包含

- 训练算法、Worker 协议、指标计算和持久化数据格式改造。
- 新增模型、数据集或后端服务。
- 自动重新训练。

## 3. 用户流程

1. 用户首次进入应用，默认位于“数据集选择”页。
2. 用户选择内置数据集或导入 CSV，查看摘要与预览。
3. 数据集校验通过后，点击“确认数据集并进入实验流程”。数据不合法时停留在当前页并显示中文错误。
4. 用户在实验流程页左侧选择模型、调整参数并开始训练。
5. 中央区域优先展示训练进度、loss/指标曲线、决策边界或聚类结果；右侧展示最终指标、混淆矩阵、预测结果和模型解释。
6. 用户可以暂停、单步、继续、停止、重置训练；训练完成后仍停留在实验流程页。
7. 用户点击“更换数据集”返回数据集选择页。新数据集确认后，清空当前训练结果但保留模型参数。
8. 用户在历史记录页查看已保存实验。历史详情只读，不覆盖当前未保存实验。

## 4. 技术方案

### 4.1 页面边界

- 复用现有 `DatasetPanel`、`ModelParameterPanel`、训练图表、结果面板和 `HistoryPage`。
- 将当前 `SinglePageWorkbench` 的数据集选择从实验流程页移除，避免重复渲染。
- 由 App 层维护顶层页面状态，默认页面为 `dataset`；页面状态切换不重置当前工作台状态。
- 实验流程页只接收当前数据集、模型配置、训练状态和结果展示所需数据。

### 4.2 实验流程页布局

宽屏布局为三栏：

```text
┌──────────────────────────────────────────────────────────┐
│ 当前数据集摘要                             更换数据集     │
├──────────────┬───────────────────────────┬───────────────┤
│ 模型与参数   │ 训练过程 / 主结果          │ 指标与解释     │
│ 训练控制     │ 曲线、边界、预测结果        │ 指标、矩阵、说明 │
└──────────────┴───────────────────────────┴───────────────┘
```

中央主区域使用最大比例；左侧参数栏保持稳定宽度；右侧结果区域允许纵向滚动。

### 4.3 状态规则

- 数据集切换只清空当前训练相关状态，不删除 IndexedDB 中的历史实验。
- 清空状态至少包括 `snapshots`、`metrics`、当前结果和当前选中实验详情。
- 模型类型和参数在更换数据集后保留。
- 训练完成后不自动跳转历史记录。
- 历史详情读取保存记录，不修改当前实验配置。

### 4.4 响应式规则

- `min-width: 1200px`：左参数 / 中央主区域 / 右结果三栏。
- `768px–1199px`：左参数与主区域两栏，结果面板移动到主区域下方。
- `< 768px`：内容纵向单列，顶部步骤导航允许横向滚动。
- 数据集页和历史记录页使用单列主内容。

## 5. 数据结构/API

不新增训练 API 和持久化字段。复用现有 `Dataset`、`ModelConfig`、`TrainSnapshot`、`ExperimentRecord`。

页面层可补充以下状态动作语义：

```ts
type TopLevelPage = 'dataset' | 'workflow' | 'history'

interface DatasetChangeAction {
  dataset: Dataset
  clearCurrentTraining: true
  preserveModelConfig: true
}
```

具体实现可映射到现有 Zustand action，不要求新增独立状态仓库。

## 6. 错误处理

- 数据集为空、CSV 非法或字段不满足要求时，在数据集页显示可理解的中文错误，并禁止进入实验流程。
- 未选择模型或参数非法时，在实验流程页对应控件附近显示中文提示，不启动训练。
- 更换数据集后显示“当前数据集已更新，请重新训练”提示，避免用户误读旧结果。
- Worker 训练错误继续沿用现有训练状态和错误提示。

## 7. 验收标准

- 首页默认显示数据集选择页，且不显示模型参数或训练结果。
- 数据集页确认后可进入实验流程页；无效数据不能进入。
- 实验流程页不再渲染第二个 `DatasetPanel`。
- 实验流程页中央训练/结果区域在宽屏上占据页面最大空间。
- 模型参数位于左侧，训练控制与参数同一侧。
- 更换数据集后模型参数保留，当前快照、指标和结果清空，并出现重新训练提示。
- 历史记录可独立查看，查看详情不会覆盖当前未保存实验。
- 1200px、768px 和手机窄屏布局无横向溢出。
- 相同数据、参数和随机种子的训练结果保持一致。
