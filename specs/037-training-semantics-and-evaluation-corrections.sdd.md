## 1. 背景与目标

静态审阅发现随机森林训练重复生成相同决策树、回归验证模式下结果页混用全量预测作为训练误差，以及部分非迭代模型在 Worker 忙于同步计算时无法及时处理停止消息。K-Means 还忽略已定义的随机种子并固定使用前 k 条样本初始化。README 与多份近期 SDD 的状态/范围也与当前实现不一致。

本规格修正这些可复现、影响教学正确性或可维护性的问题，明确现有产品边界。

## 2. 范围

### 包含

- 随机森林按固定随机种子进行 bootstrap 重采样，并在每个节点随机抽取候选特征；同一数据、参数与种子结果一致。增加并记录随机种子参数。
- K-Means 使用固定种子驱动的 k-means++ 初始化；随机种子进入模型参数及运行记录。
- 回归结果页在启用验证集时读取已保存的训练集指标；若旧记录启用了划分但没有训练指标，显示“未记录”，不以全数据结果冒充训练指标。未启用划分时仍按全量训练数据计算。
- 用户停止训练时由主线程立即终止当前 Worker，并按“已停止”保存已有快照；取消语义保持不变。
- 更新 README、总体设计和近期相关 SDD 的当前状态、功能范围、验证说明及已知限制。

### 不包含

- 新增真实图像导入、CSV 字段映射、类别特征处理、缺失值填补、自动标准化或其他数据预处理。
- 新增独立测试集、交叉验证、网格搜索、后端/GPU 训练或生产级 CNN。
- 扩展算法清单或进行与本修复无关的 UI/架构重构。

## 3. 用户流程

1. 用户选择随机森林或 K-Means 时可设置随机种子；同一数据、参数和种子重复训练得到一致模型。
2. 用户启用回归验证集并完成训练后，结果页明确展示训练子集指标与验证子集指标；旧记录缺少训练指标时明确显示未记录。
3. 用户在任一训练模型运行中点击停止，Worker 即被终止，历史中只保存运行元数据和已收到快照，不生成伪造的模型或最终指标。
4. 用户阅读 README 和规格时能区分已实现功能、产品限制和后续能力。

## 4. 技术方案

- 决策树训练支持可选的候选特征数和随机种子；不传候选特征数时保持普通决策树的全特征确定性行为。随机森林每棵树使用有放回样本，并使用 floor(sqrt(特征数))（至少 1）个随机候选特征逐节点分裂。树阈值中点计算应避免有限大数相加溢出。
- K-Means++ 使用归一化平方距离权重，避免权重求和溢出；均值和损失采用稳定累计。输入有限但两点平方距离仍超出 JavaScript 可表示范围时，明确报错，不返回非有限中心或损失。
- 随机森林和 K-Means 的种子默认值为 42，并通过现有统一参数校验、Worker 配置和运行元数据流转。
- 回归结果组件优先使用 record.evaluation.trainMetrics。若启用评估但训练指标缺失，避免回退到全量数据指标；未启用评估时可从全量预测计算训练指标。验证指标仍使用持久化的 validationMetrics。
- Worker 客户端保存当前运行的结束回调。收到停止命令后，同步通知 stopped 事件、终止 Worker 并拒绝训练 Promise，使现有停止记录路径保存快照。普通暂停/继续/单步消息继续按原协议传递。
- README 简述浏览器端教学工作台的真实能力。总体设计说明当前范围与最初 MVP 的差异；相关 SDD 的状态与实现记录对齐。明确 CSV 限制、合成图像数据、验证集可选且无测试集/交叉验证、存储上限及 CNN 教学性质。

## 5. 数据结构与接口

- RandomForestTrainConfig 增加可选 seed；KMeansTrainConfig.seed 通过统一参数定义暴露为用户参数。
- DecisionTreeTrainConfig 增加可选 maxFeatures 与 seed，只供集成训练复用；普通决策树配置行为不变。
- 随机森林结果仍为决策树集合，树节点使用原始特征索引，预测 API 不变。
- 实验记录沿用现有 config、evaluation.trainMetrics 和 runMetadata.seed，不迁移 JSON 版本。
- Worker 客户端公开方法签名不变；sendControl('stop') 的完成语义改为立即终止并产生 stopped 事件。

## 6. 错误处理

- 非法种子仍由统一参数校验阻止启动；直接算法调用遇到非法训练配置时抛出可读错误。
- K-Means 平方距离无法用有限数表示时给出可理解的范围错误；决策树对有限极大特征仍能计算有限阈值。
- Worker 已结束或停止回调已执行时，重复停止不重复发事件、不重复结算 Promise。
- 缺少历史训练指标时显示“未记录”，不得补造或误标为训练/验证指标。

## 7. 验收标准

1. 普通决策树未配置随机特征时保持确定性；随机森林同 seed 可复现，并能在多特征 XOR 样本上产生由随机候选特征导致的不同树结构。
2. K-Means 对固定 seed 可复现，初始化不再固定使用输入的前 k 个点；不同 seed 可影响候选初始化。
3. 回归验证模式显示 trainMetrics；测试通过设置全量指标与训练指标不同的数据证明不会显示全量误差；缺失旧记录指标显示“未记录”。
4. Worker 尚未发送任何响应时调用停止，客户端立即终止 Worker、发出一个 stopped 事件并使 Promise 结束；App 将该记录保存为停止状态且不渲染最终模型/指标。
5. README 不再称项目“尚未开始实现”；总体设计与近期 SDD 清楚反映现有模型任务及已知限制，近期规格状态与实现记录不冲突。
6. 相关单元/组件/Worker 测试、完整 Vitest、lint、生产构建和 git diff --check 通过；本规格记录实际验证结果。

## 8. 测试策略

- 算法测试先写失败用例：随机森林固定种子可复现、XOR 上的树多样性；K-Means 固定种子可复现且使用种子初始化。
- 回归结果组件测试覆盖训练指标、验证指标、未启用评估的旧记录及缺少训练指标的划分记录。
- Worker 客户端测试先验证停止命令在 Worker 不响应时立即终止并只结算一次；App 测试验证停止记录保持不完整语义。
- 最后运行 npm.cmd test -- --run、npm.cmd run lint、npm.cmd run build 和 git diff --check。
- 算法边界测试覆盖有限极大数的决策树分裂和 K-Means 平方距离溢出错误。
