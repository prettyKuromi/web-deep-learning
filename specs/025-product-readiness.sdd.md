# SDD-025：实验工作台可交付性修复

- 日期：2026-10-17
- 状态：开发中，待独立验收

## 背景与目标

独立设计评估发现高维训练白屏、训练控制失真、参数与执行不一致、结果和历史管理不完整。依据 docs/reviews/2026-10-17-product-readiness.md 修复 R1–R9，让现有能力可被初学者可靠使用，不新增算法或服务。

## 范围

高维安全投影；真实暂停、继续、单步和停止；统一参数及中文草稿校验；配置变更使旧结果失效；分类、回归、聚类、PCA 当前及历史结果；Dexie 单一持久化、旧历史迁移、JSON 导入导出删除；训练集口径、图例与矩阵标识；中文运行文档。

## 用户流程

选择并确认数据，选择模型并填写合法参数后训练。运行时禁止改配置，支持控制的迭代模型可暂停、单步、继续，停止立即释放 Worker。修改配置后重新训练。完成后查看对应任务结果、有效参数与保存状态；历史支持导入、导出、删除和刷新恢复，导入非法文件保持原历史。

## 技术方案

- 仅二维分类绘制决策边界，高维使用前两个特征散点投影并说明限制。
- 参数定义集中为 UI、执行与记录的唯一默认来源；输入保留字符串草稿，校验为空、有限数值、范围及整数。
- Worker 训练通过可等待的迭代检查点让出事件循环；暂停阻止推进，单步放行一个迭代，停止终止 Worker；一次拟合模型禁用不支持的控制。
- 配置编辑重置当前结果，训练记录保存启动时的数据、参数和 CNN 结构快照。
- 任务结果组件由当前和历史复用，分类显示训练集指标及带方向类别的混淆矩阵；回归显示误差及预测，聚类显示簇/噪声及投影，PCA 显示方差与投影。
- Zustand 仅管理会话，Dexie 保留最近 20 条；初始化合并不覆盖新训练。安全迁移旧 localStorage，保存失败保留会话结果并显式提示未保存。
- JSON v1 保持兼容，先深度验证所有记录后写入；合法模型、维度、参数、预测、指标和模型结构校验，批量事务避免部分导入。

## 数据结构/API

增加集中模型参数定义与校验；Worker 检查点接收 pause/resume/step；记录可选 CNN 结构，保持旧 v1 可导入；增加持久化加载、批量导入、删除、保存状态接口。任务结果从 ExperimentRecord 派生，不将当前 UI 参数写回历史。

## 验收标准

1. 三、四维 KNN/MLP 当前与历史不白屏，不调用维度错误的边界预测。
2. 逻辑回归、SVM、MLP、CNN 暂停后进度稳定，单步恰好一个迭代，继续恢复，停止释放 Worker。
3. UI/执行/历史/导出默认值一致；非法草稿不能训练，中文就地提示；运行时不可改语义配置，变更后无旧结果冒充新结果。
4. 四种任务当前与历史都有真实结果及任务摘要，回归非数值标签提前提示。
5. 导出→删除→导入→刷新闭环可用，非法导入不修改原历史；保存失败不变为训练失败；迁移旧历史不静默丢失。
6. 分类说明训练集口径；矩阵与散点类别可识别；CSV 最后一列标签规则及限制明确。

## 测试策略

先写关键行为失败回归再实现；单元覆盖参数、控制、投影、任务结果、持久化校验与失败。真实 Playwright 检查高维训练、暂停单步、配置失效、非分类结果和历史交换。执行 npm test、npm run lint、npm run build、git diff --check。记录实际命令与结果，开发和验收角色分离。
